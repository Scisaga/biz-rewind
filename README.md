**重读和重写商业、经济学经典，把理论讲清楚，把适用条件和局限写明白，再把其中可操作的部分整理成分析方法。**

这个项目用于系统学习商业与经济学，也希望让学到的东西能够帮助现实判断：分析一个组织的问题、理解一项经济政策，或者判断一块业务的竞争优势能否持续。

读者应当能从每个主题中找到四样东西：它原来要解决的问题、核心机制、成立与失效的条件，以及现实中的用法。7Powers 在此基础上进一步尝试把分析方法写成 AI 可以执行的规格。

## 怎样重读经典

项目的写作围绕三个动作展开：

- **理解原著**：还原作者面对的问题，讲清概念和推理，而不只记住结论。
- **检查边界**：补充后续研究、争议和反例，说明理论在哪些条件下成立，哪些说法需要修正。
- **用于判断**：联系现实案例，提炼要问的问题、要查的证据，以及足以推翻判断的条件。

例如，读到“规模经济”时，需要进一步理解固定成本怎样形成成本差距、这个差距针对哪些竞争者，以及它是否足以阻止对手追赶。这些问题决定了理论能否用于眼前的业务。

## 从读懂理论到执行分析

7Powers 尝试把一次商业判断展开为可以重复执行、检查和更新的过程：

1. 划分具体业务，确定增长阶段，列出现有竞争者、潜在进入者和功能性替代者。
2. 检查对手为什么难以追赶，再用指标和证据判断竞争优势是否成立。
3. 记录结论的置信度、推翻它的条件和需要重估的时间，以便持续跟踪。

中文书稿解释这套方法为什么这样做；[七力判据表](7Powers-七种力量/方法论/02-判据表-七力可执行规格.md) 写明取数口径、指标、否决条件和输出字段，供 AI 助手执行分析时引用。两份产物共享同一套判据。

目前已有判据规格、[分析管线设计](7Powers-七种力量/方法论/03-分析管线架构.md)，以及 [20 个案例的第一轮纸面回测](7Powers-七种力量/方法论/04-判据回测与阈值校准.md)。纸面回测用于检查判据的结构、顺序和阈值方向；精确阈值仍需真实数据验证。管线实施暂缓，数据接入和自动运行尚未在本项目中实现。详细进展见 [7Powers 的 README](7Powers-七种力量/README.md)。

## 怎样开始阅读

- **学习商业与管理**：从《重读商业经典》的总目录选择与当前问题有关的章节；[后记](重读商业经典/后记.md) 汇总了共通线索、理论冲突和可用的决策方法。
- **理解经济现象**：从《经济学如何改变我们的生活》的总目录选择主题；[后记](经济学如何改变我们的生活/后记.md) 集中讨论结论的条件与边界。
- **研究业务的竞争优势**：先读 7Powers 的总目录和章节，再结合判据表与回测记录理解分析过程。

对重要结论，可沿各章的延伸阅读回到原著和研究来源核对。原书资料、独立解读和项目补充分别维护；7Powers 中标注为【拟定】的阈值属于项目假设。

## 文件与维护

当前产物以 Markdown 书稿和方法论文档为主，使用支持 Markdown 的编辑器即可阅读。每套内容放在对应文件夹内：`00-全书总目录.md` / `00-总目录.md` 提供章节导航，`原书目录.md` 保存书目信息与原始目录，7Powers 的 `方法论/` 和 `原文/` 分别保存分析规格与原文参考资料。

新增章节或移动文件时，同步更新目录和相对链接。参与维护的 AI 助手遵循 [AGENTS.md](AGENTS.md) 中的写作、来源和检查约定。
