## 引子：所有权到底是什么

先问一个看起来幼稚的问题：**"拥有一台机器"是什么意思？**

日常回答是"这台机器是我的"。但对经济学家来说，这个回答等于什么都没说。

更细一点的回答可能是"我有权使用它、有权卖掉它、有权获得它产生的收益"。**但这些权利都可以通过合同转让出去。**我可以把机器租给你，让你使用它并获得全部收益，为期二十年。**那么在这二十年里，它到底是谁的？**

**哈特给出的答案，是本章的核心，也是他获得诺贝尔奖的理由：**

> **拥有一样东西，就意味着在所有合同没有写到的情况下，你有权决定它怎么用。**

**这个权利叫剩余控制权。**

**"剩余"这个词是关键：合同写明的部分（特定控制权），已经按约定分配掉了；而合同没写到的一切——那些没被想到、没被约定、或者无法被清楚描述的情况——的决定权，归所有者。**

**而由于合同必然是不完全的（第 12 章），"剩余"这部分总是存在，而且往往很大。**

**于是所有权就有了实质内容：它是一种在意外发生时的最终拍板权。而正是这个权利，决定了双方在事后重新谈判时的地位，进而决定了双方在事前愿意投入多少。**

**这条从"所有权 → 事后谈判地位 → 事前投资激励"的因果链，就是产权理论的全部。**

## 起点：接过威廉姆森的问题，但换一个答案

第 12 章讲了威廉姆森：因为合同不完全、因为存在专用投资，所以事后可能被敲竹杠；为了防止敲竹杠，就要选择合适的治理结构，包括纵向一体化。

**哈特（与桑福德·格罗斯曼、约翰·摩尔一起）接受了这个出发点，但对它提出了一个尖锐的质疑：**

> **威廉姆森解释了为什么一体化有好处，但没有解释一体化的成本是什么。**

**这是一个致命的问题。**因为如果一体化只有好处，那么最优的组织形式就是**把整个经济合并成一家公司**——而这显然荒谬。

**威廉姆森的回答（官僚成本、激励弱化、影响力成本）在直觉上是对的，但它们是被描述出来的，不是被推导出来的。**

**哈特要做的，是构造一个模型，让一体化的成本从同一套假设中被推导出来——也就是说，用同一个机制同时解释"为什么要合并"和"为什么不该全部合并"。**

**他找到的机制，就是剩余控制权对投资激励的影响。**

## GHM 模型：一体化为什么必然有代价

### 设定

模型的结构极简，但每一步都很重要：

- **有两方**：M1 和 M2（可以理解为两家企业，或两个部门）；
- **有两项资产**：A1 和 A2；
- **双方都需要在事前做一项专用投资**（比如 M1 培养专门服务 M2 的技术能力，M2 建立专门适配 M1 的产线）；
- **这些投资是"关系专用的"**：只有在双方继续合作时才有价值；
- **关键假设：投资无法写进合同。**因为它是"努力程度"、"人力资本积累"、"创意投入"这类无法被第三方（比如法院）验证的东西。

### 事情如何展开

**第一阶段：双方各自决定投资多少。**

**第二阶段：合作产生收益，双方分配这个收益。**由于合同不完全，分配是通过**事后谈判**决定的。

**第三阶段——推理的关键：事后谈判的结果，取决于双方各自的"外部选项"（谈崩了各自能得到什么）。**

**而外部选项取决于谁拥有资产。**

如果 M1 拥有两项资产，那么谈崩时 M1 仍能使用这两项资产（虽然效率降低），而 M2 什么也没有。**因此 M1 在谈判中会拿到更大的份额。**

### 结果一：所有权应该给"投资更重要"的那一方

现在把逻辑倒推回第一阶段。

**每一方在决定投资多少时，看的是"我这笔投资，我自己能拿回多少"。**

如果 M1 知道自己在事后谈判中只能拿到收益的一半，那么他投资的动力就只有社会最优水平的一半——**因为他承担 100% 的投资成本，却只能获得 50% 的收益。**这就是**投资不足**。

**而所有权改善了所有者的处境：拥有资产 → 外部选项更好 → 事后拿得更多 → 事前更愿意投资。**

**推论：所有权应该分配给那个"边际投资对总价值贡献更大"的一方。**

**这是一个非常具体、可以拿去用的判据。**它把"该谁拥有"从一个法律或历史问题，变成了一个关于**谁的努力更关键**的问题。

### 结果二——最重要的一条：一体化必然损害另一方

**这是哈特相对于威廉姆森最重要的推进。**

所有权是**零和**的：**M1 获得了资产的所有权，就意味着 M2 失去了它。**

于是：

- **M1 的投资激励改善了**（他事后能拿更多）；
- **M2 的投资激励恶化了**（他事后能拿更少）。

**一体化不是"消除了摩擦"，而是"把摩擦从一方转移到了另一方"。**

**结论：只有当 M1 的投资比 M2 的投资更重要时，一体化才值得。如果两方的投资同等重要，一体化会让总投资下降，非一体化反而更好。**

**这就是哈特要找的那个"一体化的成本"——它是从同一个机制中推导出来的，而不是外加的假设。**

**这个结论有巨大的现实意义。**它意味着：

> **当你收购一家公司时，你改善了自己的激励，同时确定无疑地损害了被收购方的激励。**

**如果被收购方的努力（尤其是创始人、核心团队的努力）对价值创造至关重要，那么收购在结构上就是错的，无论支付了多高的价格、无论签了多少对赌协议。**

**这解释了一个反复出现的现象：技术型收购中，创始人在锁定期结束后大规模离开，被收购业务随后衰落。这不是文化问题，是产权理论的直接预测。**

### 结果三：资产互补性决定应不应该合并

哈特与摩尔进一步给出了一条判据：

- **高度互补的资产**（缺一个另一个就几乎没用）**应该由同一个所有者持有。**因为分开持有时，任何一方都可以用"不给你用"来卡住对方，双方的投资激励都被严重削弱。
- **相互独立的资产**（各自都能单独产生价值）**应该分开持有。**因为合并只会削弱一方的激励，而没有换来任何协调收益。

**一个直观的例子：**铁路的路轨和列车是高度互补的（没有轨的车和没有车的轨都毫无价值），所以它们通常在同一个所有权之下，或者由极其详尽的监管合同来替代所有权。而一家餐厅和它旁边的花店，资产是独立的，合并它们不会产生任何协调收益。

### 结果四：当关键资产是人的时候，所有权就不那么重要了

**这是产权理论一个非常深刻的推论。**

**因为在现代社会，人不能被拥有。**

**所以：如果一个业务的关键资产是人力资本（知识、创造力、客户关系），那么"拥有这家公司"能带来的剩余控制权就很有限——因为最重要的那项资产随时可以走出大门。**

**这解释了一系列现象：**

- **律师事务所、咨询公司、投资银行、广告公司、对冲基金，为什么大多采用合伙制而不是外部股东制？**因为关键资产是合伙人的人力资本，让他们拥有企业才能提供正确的激励。
- **为什么这类企业的"收购"往往失败？**因为你买到的是办公室租约和品牌，而真正创造价值的资产在每天下午六点走出大楼。
- **为什么科技公司要用大量股权而不是现金来支付？**因为它们在试图把人力资本的所有者变成物质资本的所有者，从而把两者绑在一起。

**一句可以记住的话：你能收购一家工厂，你不能收购一群人。当价值主要来自人时，产权的杠杆就变短了，你必须依靠别的机制——股权、声誉、职业发展、以及第 15 章要讲的东西。**

## 与威廉姆森的区别

这两章讲的是同一个问题，但重心不同，值得明确对比：

| 维度 | 威廉姆森（交易成本经济学） | 哈特（产权理论） |
| --- | --- | --- |
| 关注的成本 | **事后的**：讨价还价、适应不良、纠纷、协调失败 | **事前的**：投资激励被扭曲 |
| 一体化的好处 | 提高适应性，减少事后摩擦 | 改善所有者一方的投资激励 |
| 一体化的成本 | 官僚成本、激励弱化、影响力成本（描述性的） | 必然损害另一方的投资激励（**推导出来的**） |
| 方法 | 丰富的案例与比较制度分析 | 严格的形式化模型 |
| 优点 | 贴近现实，涵盖混合形式的多样性 | 逻辑严密，预测明确，可被检验 |
| 缺点 | 难以精确检验，概念难以量化 | 高度抽象，忽略了大量现实中的治理细节 |

**两者不是对立的，而是同一枚硬币的两面。**一个更完整的判断是：**当事后的协调问题是主要矛盾时，用威廉姆森；当事前的投入激励是主要矛盾时，用哈特。**

**而在实践中最有用的一条经验是：如果价值主要来自"双方都必须持续投入努力"，那么哈特的框架更相关，而它的结论是——不要轻易改变所有权。**

## 应用一：政府应该做什么——监狱的案例

1997 年，哈特与安德烈·施莱费尔、罗伯特·维什尼发表了一篇论文，题为《政府的适当范围：理论及其在监狱上的应用》。

**这是产权理论最漂亮的一次应用，因为它把一个高度意识形态化的争论（该不该私有化），变成了一个可以逐项判断的技术问题。**

### 论证

私营企业的所有者拥有剩余控制权和剩余索取权，因此他有**极强的动力去削减成本**。

**问题在于，降低成本有两种方式：**

1. **好的方式**：提高效率、改进流程、更好的管理；
2. **坏的方式**：降低那些"合同上没写清楚、或者写了也难以验证"的质量维度。

**关键判断因此变成：在这项服务里，质量的可契约性有多高？**

- **如果质量可以被清楚地写进合同并验证**（比如垃圾清运：垃圾有没有被运走，一看便知），**那么私有化的好处（成本压力）大于坏处，应该外包。**
- **如果质量的关键维度无法被写清或验证**（狱警是否过度使用暴力、是否有系统性的忽视、囚犯的改造效果），**那么削减成本的动力会转化为质量的恶化，而这种恶化不会体现在任何可考核的指标上。**

**他们的结论是：监狱的核心质量维度大多不可契约，因此私营监狱的强成本激励会带来严重的质量损失；这类服务应当保留在公共部门。**

**而对于质量易于测量的辅助服务（餐饮、清洁、维护），外包是合适的。**

### 后来的证据

大量对美国私营监狱的实证研究，与这个预测大体一致：**私营监狱在成本上的节省往往有限，而在暴力事件、人员配备、员工流失率上的表现通常更差。**

### 这个框架的普遍价值

**这条判据可以直接搬到任何一个外包决策上：**

> **先列出这项工作的所有质量维度，然后逐条问：这一条能不能被写进合同，并被第三方验证？**

- **能验证的部分**（响应时间、交付数量、系统可用率、合规检查项）→ 外包很安全，强激励会带来真实改进；
- **不能验证的部分**（代码的可维护性、客服的真诚程度、对长期风险的审慎、对用户的诚实）→ **强成本激励会精确地攻击这些维度**，因为它们是"免费"的削减对象。

**最重要的含义是：外包失败往往不是因为供应商不好，而是因为你把一项质量不可契约的工作，交给了一个有强烈成本削减动机的主体。这个组合在结构上必然出问题。**

## 应用二：债与股——控制权的状态依赖

产权理论对公司金融的贡献同样重要，而它给出了一个与传统教科书完全不同的视角。

**传统视角**：债和股的区别是现金流的分配方式——债权人先拿固定的，股东拿剩下的。

**哈特（以及阿吉翁与博尔顿）的视角：债和股的真正区别，在于它们如何分配控制权，而且这个分配是状态依赖的。**

- **公司经营正常、能按时还本付息时**：**控制权在股东（及其代理人管理层）手中。**债权人无权干涉经营决策。
- **一旦违约**：**控制权自动转移给债权人。**他们可以要求重组、更换管理层、清算资产。

**换句话说：债务是一种"在坏状态下自动移交方向盘"的机制。**

**这个视角解释了几件传统理论解释不了的事：**

- **为什么公司要举债，而不是全部用股权融资？**因为债务提供了一种可信的纪律：**管理层知道，如果经营不善到无法偿债的地步，他们会失去控制权。**这是一种自我约束的承诺装置（与第 4、5 章的可信承诺问题同构）。
- **为什么债务契约里有大量看似繁琐的限制性条款**（不得再借新债、不得出售核心资产、必须维持某个财务比率）？**因为它们是在提前定义"控制权转移的触发条件"**——把不完全契约的缺口，用可验证的财务指标部分填上。
- **为什么破产法如此重要？**因为破产法本质上就是一部关于**控制权如何在坏状态下重新分配**的法律。

**这个洞见对创业者尤其有用：融资协议里真正重要的条款，往往不是估值，而是那些决定"在什么情况下谁说了算"的条款——董事会席位、一票否决权、清算优先权、对赌触发条件。估值决定你分多少，控制权条款决定你还是不是那个决定怎么分的人。**

## 转向：合同作为参照点（2008）

哈特后来的研究出现了一个重要转向，值得记录，因为它显示了这位理论家对自己框架局限的诚实。

2008 年，他与摩尔发表了《作为参照点的合同》。

**动机**：标准的不完全契约理论假设，事后重新谈判总是能达成有效率的结果（双方会理性地把蛋糕做大，只是分配有争议）。**但现实中，重新谈判经常是破坏性的——关系变坏、合作质量下降、双方开始互相消耗。**

**他们提出的新机制是：合同不只是一份权利义务清单，它还创造了"应得感"（entitlement）。**

- 双方各自把合同解读得对自己有利（在合同允许的范围内）；
- 当事后的实际安排低于自己的"应得"预期时，会产生**不满**（aggrievement）；
- 不满的一方会以**"敷衍"**（shading）来报复——**在合同没有强制规定的那些维度上，降低配合程度。**

**这个机制解释了一个所有管理者都熟悉、但标准理论无法处理的现象：**

> **一份在法律上完全被履行的合同，可以在实质上被彻底破坏——因为对方做到了所有写明的事，同时不做任何没写明的事。**

**"按合同办事"作为一种消极抵抗，比违约更难对付，因为它无懈可击。**

**这个转向的意义在于，它把行为经济学（第 21 章）的元素引入了契约理论：人不只是在计算收益，他们还在乎自己是否被公平对待，而这种在乎会改变他们的实际行为。**

**它给出的实践建议很具体：一份"灵活的"合同（留下大量事后调整空间）未必更好，因为灵活性会给双方留下不同的"应得"解读空间；而一份适度刚性、双方对"什么是公平"有共同理解的合同，可能带来更好的实际合作——即使它在纸面上看起来不够优化。**

## 霍姆斯特罗姆：同年的另一半奖

2016 年的诺贝尔奖由哈特与本特·霍姆斯特罗姆共享。**霍姆斯特罗姆研究的是契约的另一半：当行为可观察但不可完全度量时，如何设计激励。**这里只讲他最有实践价值的一项工作。

**多任务模型（1991，与保罗·米尔格罗姆合著——正是第 14 章的主角）。**

**核心命题**：当一个人要同时做多项任务，而这些任务的可度量程度不同时，**给可度量的任务加强激励，会导致他系统性地放弃不可度量的任务。**

**因此，最优的做法可能是——对所有任务都使用较弱的激励。**

**这个结论极其反直觉，也极其重要：**

- **销售人员如果只按成交额提成**，就会牺牲客户关系维护、售后服务、以及诚实告知产品缺陷；
- **教师如果只按考试成绩考核**，就会牺牲那些不进入考试的能力培养；
- **工程师如果只按功能交付数量考核**，就会牺牲代码质量、文档、和技术债的处理；
- **客服如果只按通话时长与结案率考核**，就会牺牲问题的真正解决。

**霍姆斯特罗姆与米尔格罗姆给出的三个解法值得记住：**

1. **降低所有维度的激励强度**（这就是为什么很多复杂工作用固定工资而非计件工资——固定工资不是激励不足，而是刻意的"低强度激励"）；
2. **限制不可度量任务的替代空间**（比如禁止某些行为，而不是奖励另一些）；
3. **改变工作的组合方式**（把可度量和不可度量的任务分给不同的人）。

**注意：这与哈特的监狱论证是同一个逻辑的两个版本。**哈特说：不可契约的质量会被成本压力侵蚀。霍姆斯特罗姆说：不可度量的任务会被强激励挤出。**两者共同构成了本章最有实用价值的那条原则。**

## 落地：可以直接用的六条

**一、所有权 = 意外发生时谁说了算。**

**任何一份协议，除了看条款，还要问一句：合同没写到的情况发生时，谁有权决定？**

- 合资公司的僵局条款是什么？
- 联合开发的知识产权，改进部分归谁？
- 外包的数据，谁有权访问和迁移？
- 平台规则变更时，你有没有申诉权，还是完全由对方单方面决定？

**这些"剩余"条款，在关系顺利时毫无用处；在关系出问题时，它们就是全部。**

**二、收购必然损害被收购方的激励——所以只有当你的投入更关键时才该做。**

**在做收购决策时，问三个问题：**

1. 未来创造价值的关键投入，主要来自我方还是对方？
2. 如果对方的核心团队在两年内离开，这笔收购还值多少？
3. 我能不能通过合作、投资、长期合同达到同样的目的，而不改变所有权？

**如果价值主要来自对方的持续努力，那么改变所有权是在削弱那个最重要的引擎。**

**三、当关键资产是人时，产权的作用有限，要换工具。**

**这一条对所有知识型组织都成立。**你无法通过"拥有"来锁住人力资本，因此必须依靠：股权与长期激励、职业发展、声誉与专业认同、以及让人愿意留下的关系与环境。

**推论：一家公司如果把管理重心放在控制（流程、审批、竞业限制）而不是吸引上，它其实是在用管理物质资本的方式管理人力资本，这在结构上是错配的。**

**四、外包之前，先做一次"可契约性清单"。**

把这项工作的所有质量维度列出来，逐条标注：**能不能被写清楚？能不能被第三方验证？**

**不能被验证的那些维度，就是外包之后一定会被牺牲的维度。**

**如果那些维度恰好是最重要的，就不要外包；如果它们不重要，就放心外包。**

**这个练习比任何"核心/非核心"的讨论都更有用。**

**五、警惕"按合同办事"式的敷衍。**

**当对方觉得自己被不公平对待时，报复的方式通常不是违约，而是精确地只做合同规定的事。**

**信号很明显：突然开始严格援引条款、开始要求书面确认一切、停止提供任何"分外"的配合。**

**一旦出现这些信号，追究合同责任是没有用的——因为对方并没有违约。唯一的解法是回到那个"应得感"上：搞清楚他觉得自己在哪里被亏待了。**

**六、给可度量的部分加激励，等于给不可度量的部分减激励。**

**这是霍姆斯特罗姆多任务模型最实用的一条。**

**每次你要设立一个新的考核指标时，先问：这个指标会让人放弃什么？**

**如果答案是"会放弃一些重要但测不出来的东西"，那么正确的做法可能不是把指标设计得更精细，而是把激励强度调低。**

## 争议与修正

**一、"不完全契约无关"批评。**

这是产权理论受到的最严肃的理论挑战，来自埃里克·马斯金与让·梯若尔（1999）。

**他们的论证是：即使双方无法事先描述所有的物理状态（"如果发生了 X"），他们仍然可能描述各种情形下的收益（"如果我的价值是高，那么…"）。而只要收益可以被描述，就可以设计一套精巧的机制（比如让一方报价、另一方选择买或卖），来实现最优结果。**

**如果这个论证成立，那么合同的不完全性就不重要了，产权理论的基础就被抽掉了。**

**哈特与摩尔的回应（也是《合同作为参照点》的动机之一）有两条：**这类机制在现实中极其复杂、几乎从不被使用；而且它们依赖于双方不会重新谈判、不会串谋——**这些假设本身比不完全契约更不现实。**

**这场争论至今没有完全解决，但实践者普遍站在哈特一边，因为现实中的合同确实简单而不完全。**

**二、实证检验困难。**产权理论的核心变量（谁的投资更重要、资产的互补程度）极难测量。**因此，它主要作为一个分析框架被使用，而不是作为一个被反复检验的实证理论。**这与第 12 章威廉姆森理论有大量实证支持形成对比。

**三、过于抽象，忽略了组织的丰富性。**批评者（包括威廉姆森本人）指出：GHM 模型里的"企业"只是一堆资产，没有层级、没有文化、没有惯例、没有内部的权力斗争。**它精确地解释了一个很窄的问题，代价是把组织的绝大部分内容抽象掉了。**

**四、"所有权是零和的"这一假设本身可以被放松。**现实中存在大量共同所有、分层所有、条件所有的安排（合资、可转换优先股、期权、特许经营）。**这些安排恰恰是在试图突破模型中的零和约束，而模型对它们的处理相对有限。**

**五、私有化结论的适用边界。**哈特—施莱费尔—维什尼的框架在监狱上得到了较好的验证，但把它推广到所有公共服务需要谨慎——**因为"可契约性"本身会随着技术进步而变化。**过去无法测量的东西（服务质量、用户满意度、结果指标），今天有些已经可以测量了。**这意味着最优的公私边界不是固定的，它会随着测量技术而移动。**

## 结语：真正重要的条款，是关于意外的条款

这一章的结论可以压缩成一句话：

> **在一份长期关系里，写明的部分决定了顺利时怎么办，而没写明的部分决定了出问题时谁说了算——后者才是真正的权力所在。**

哈特的贡献，是把这个直觉变成了一套可以推演的理论，而这套理论的推论往往是反直觉的：

- **收购不是纯粹的增强，它必然削弱被收购方的动力**；
- **强激励不是纯粹的好事，它会精确地攻击那些无法被度量的维度**；
- **私有化的成败，不取决于意识形态，而取决于质量能不能被写进合同**；
- **当价值来自人时，所有权这个工具的杠杆就变短了**。

**而它们全都来自同一个源头：合同是不完全的，因此总有一块空白；而那块空白由谁支配，会一路倒推回去，改变每个人今天愿意付出多少。**

那么，一个非专业读者该从这一章带走什么？

**第一，学会区分"分蛋糕的条款"和"决定谁来切蛋糕的条款"。**前者是价格、比例、金额，人们通常会仔细讨论；后者是决策权、否决权、终止权、争议解决方式，人们通常一带而过。**而在任何一段关系出问题的时候，起作用的全是后者。**

**第二，接受一个不舒服的事实：你无法通过把合同写得更长来解决这个问题。**有限理性是硬约束。**因此正确的努力方向不是穷尽条款，而是把"意外发生时的决策规则"设计好——包括谁决定、多久决定、以及怎样退出。**

**第三，也是最重要的：任何一次权力结构的改变，都会改变所有人的努力程度，而且改变常常发生在你看不见的地方。**

**你收购了一家公司，创始人的努力会下降一点；你收紧了一个部门的自主权，他们的主动性会下降一点；你把一项工作的考核变严了，那些考核不到的部分会变差一点。**

**这些变化都不会出现在任何报表上，也不会有人向你汇报。它们只是安静地发生，然后在一两年后以"业绩不及预期"的形式出现。**

**产权理论最大的价值，就是让你能够在做出改变之前，预见到这些看不见的反应。**

## 本章要点回顾

| 主题 | 核心结论 |
| --- | --- |
| 所有权的定义 | **所有权 = 剩余控制权**：在合同没有写到的情况下拍板的权利 |
| 因果链 | 所有权 → 事后谈判地位 → 剩余分配 → **事前投资激励** |
| 对威廉姆森的推进 | 威廉姆森没能推导出一体化的成本；哈特用同一机制同时解释合并的收益与代价 |
| 结果一 | 所有权应给"边际投资更重要"的一方 |
| 结果二（最重要） | 所有权是零和的：一体化改善所有者激励，**必然损害对方激励**——总投入可能下降 |
| 现实含义 | 收购必然削弱被收购方动力；若价值来自对方持续努力，收购在结构上就是错的 |
| 结果三 | 高度互补的资产应共同所有；相互独立的资产应分开所有 |
| 结果四 | 关键资产是人力资本时，所有权杠杆很短——解释了合伙制、股权支付与技术收购的失败 |
| 与威廉姆森的分工 | 威廉姆森看**事后**摩擦，哈特看**事前**激励；协调问题为主用前者，投入问题为主用后者 |
| 监狱论证 | 判据是**质量的可契约性**：可验证 → 外包安全；不可验证 → 强成本激励会精确侵蚀质量 |
| 债与股 | 二者的本质区别是**状态依赖的控制权**：正常时归股东，违约时自动移交债权人 |
| 创业者的含义 | 融资协议中重要的不是估值，而是决定"什么情况下谁说了算"的条款 |
| 合同作为参照点 | 合同创造"应得感"；不满会转化为"敷衍"——完全履约的同时彻底破坏合作 |
| 霍姆斯特罗姆多任务 | 强化可度量任务的激励 = 削弱不可度量任务；解法是降低整体激励强度或分离任务 |
| 主要争议 | 马斯金—梯若尔的"无关性"批评、实证检验困难、抽象掉了组织的绝大部分、可契约性会随技术变化 |
| 给决策者 | 关注"意外时谁说了算"；收购前问关键投入来自谁；人力资本要换工具；外包前做可契约性清单；警惕"按合同办事"的敷衍；新指标必问它会挤掉什么 |
