# 经济学如何改变我们的生活

> 基于陈永伟《经济学如何改变我们的生活》（中国民主法制出版社，2024）的目录结构，对三十二位经济学家及其思想的独立解读与重写。
>
> **说明**：本书为原创解读，非对任何既有出版物文字的复制。每章均对应该经济学家的真实贡献，并补充了后续研究的修正、当代实证挑战与现实应用案例。

## 全书结构

四部分，二十三章，覆盖三十二位经济学家 + 后记。

与《重读商业经典》"一章一部书"不同，本书是"一章一个人（或一组人）"：每章从这位学者面对的**真实问题**出发，讲清他给出的答案、答案后来被怎样修正、以及这套思路今天还能用在哪里。

## 每章的固定结构

1. **学者小档案**——生平、任教、获奖、核心贡献、代表作
2. **他面对的问题**——这套理论是为了回答什么现实困境而生的
3. **正文**——核心理论逐层展开，尽量用一个可复述的机制而非术语堆砌
4. **落地**——这套思路在企业决策、投资、政策与个人生活中的具体含义
5. **争议与修正**——被后续研究推翻、削弱或误用的部分
6. **本章要点回顾**——一张表，可用于快速复习
7. **延伸阅读**——含对立观点的书目

---

## 五条贯穿全书的线索

1. **信息是经济学的真正主角**——斯密的价格 → 弗里德曼的货币 → 卢卡斯的预期 → 威廉姆森的交易成本 → 米尔格罗姆的拍卖 → 克雷普斯的声誉
2. **约束比意愿更能解释行为**——凯恩斯的有效需求 → 哈特的剩余控制权 → 阿西莫格鲁的制度 → 戈尔丁的贪婪工作
3. **宏观的每一次进步，都是一次微观基础的补课**——萨缪尔森 → 卢卡斯 → 巴罗 → 清泷信宏
4. **相关不是因果，而经济学花了一百年才学会证明这一点**——卡德 → 安格里斯特与因本斯 → 巴纳吉、迪弗洛与克雷默
5. **理性人假设的松动，是这门学科最重要的自我修正**——卡尼曼 → 格兰诺维特 → 阿克洛夫式的社会嵌入

## 六组真实的争论

| 议题 | 一方 | 另一方 |
| --- | --- | --- |
| 危机时政府该做什么 | 凯恩斯：需求管理 | 卢卡斯、巴罗：政策无效与李嘉图等价 |
| 通胀的根源 | 弗里德曼：始终是货币现象 | 布兰查德：供给冲击与预期锚定同样关键 |
| 增长靠什么 | 索洛、罗默：技术与知识 | 阿西莫格鲁：技术本身是制度的产物 |
| 全球化的代价 | 巴格瓦蒂：自由贸易利大于弊 | 卡德、阿西莫格鲁：分配后果被长期低估 |
| 不平等会自动扩大吗 | 皮凯蒂：r > g 是结构性力量 | 主流批评：资本回报率随积累下降 |
| 人是理性的吗 | 曼昆的教科书：从理性人出发 | 卡尼曼、格兰诺维特：系统性偏差与社会嵌入 |
