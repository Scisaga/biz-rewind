# 第 2 章　阶段闸门：什么时候才有机会

> 在检验任何一种具体力量之前，先确定这门生意处在哪个增长阶段。**这一步能把七种可能性砍到两三种。**

---

## 一、为什么这章被提到前面

在原书里，这是第 9 章——最后一章正文，放在七种力量全部讲完之后。作为一本讲道理的书，这个顺序是对的：得先知道七种力量分别是什么，才能讨论它们何时出现。

**但作为一套分析流程，这个顺序是反的。**

真实分析的第一个动作不是"这家公司有哪种护城河"，而是"**这门生意现在处在什么阶段，因而哪几种护城河在理论上还有可能**"。

Helmer 自己也这么说：

> 任一增长阶段，你最多只需要探索 **3** 种新力量。

七砍到三，工作量少一半以上，而且**砍掉的那部分不是省略，是排除**——它们在这个阶段根本不可能建立。这不是节省，是纪律。

---

## 二、三个阶段

分界用的是**业务的单位增速**：

| 阶段 | 界定 |
| --- | --- |
| **原生 Origination** | 跨过"非买不可"的门槛之前，销售尚未起量。**可以长期没有销售** |
| **起飞 Takeoff** | 爆发式增长期 |
| **稳定 Stability** | 增速跌破约 **30–40%/年**。业务可能仍在快速增长，只是不再"爆发" |

### 30–40% 这个分界线的含义

Helmer 的解释不是拍脑袋：**在这个增速下，市场约两年翻一番。**

这意味着市场足够流动——领导地位可以易主，而在位者**来不及做出会摧毁价值的反制**。低于这个速度，市场结构就板结了：谁想抢份额，对手有充分的时间和动机打回来，抢份额的价格会被抬到它本身的价值之上。

**所以这条线的本质不是"增长快慢"，而是"份额还能不能以划算的价格买到"。**

### 三个必须注意的口径问题

**第一，是业务增速，不是行业增速。** 业务增速才反映**这家公司**面临的通量。一个在成熟行业里刚切入新细分、自身增速 80% 的业务，处在起飞期，尽管行业早已成熟。

**第二，单位增速优先于金额增速。** 涨价带来的收入增长不代表通量。半导体、大宗、周期品尤其要小心。

**第三，它不等于产品生命周期。** Helmer 特别警告了这一点，因为混淆的后果很严重：

| | 产品生命周期 | 力量进程 |
| --- | --- | --- |
| 分界依据 | 行业销量曲线 | **业务**单位增速 |
| 起点 | 导入期（已有产品上市） | **原生期可能长期无销售** |
| 覆盖 | 导入/成长/成熟/衰退 | 稳定期**覆盖了成长后段一直到衰退** |

关键差别：**生命周期的"成长期"同时包含了力量进程的起飞期和一部分稳定期。** 而这两段的可得力量完全不同。用生命周期来判断力量窗口，会把最关键的时点搞错。

---

## 三、真正要问的是：壁垒什么时候建立

Helmer 把问题又收窄了一层：

> 力量 = 好处 + 壁垒。而好处很常见，往往对企业价值没什么正面影响，因为它们通常会被完全套利掉。**价值的真正来源在于那些罕见的、能阻止套利的情形——那是壁垒的功劳。因此，力量的决定性获得，往往与壁垒的建立同步。**

所以问题不是"力量什么时候出现"，而是"**壁垒什么时候必须建成**"。

而壁垒只有**四种机制**，每一种都天然绑定一个阶段：

### 抢份额成本（Cost of Gaining Share）→ 只在起飞期

> 原生期根本没有份额可言，销售都还没发生。起飞期，能否快速扩张取决于渠道位置、产品特性、传播方式、地理、产能约束等等一大堆因素，因此**份额的"价格"通常不反映它的长期内在价值**。等到了稳定期，最有效的打法已经众所周知、人人可用，客户的关注点从"我能不能买到"变成"哪家更便宜"——这时每个玩家都清楚份额值多少钱，会相应博弈，把它的价值套利掉。

**一句话：只有在起飞期，份额才能以划算的价格买到。**

规模经济、网络经济、转换成本，全靠这个机制，所以全部只能在起飞期建立。

### 附带损害（Collateral Damage）→ 只在原生期

新商业模式正是让挑战者起飞的那个东西，**它必须先于起飞发生**。

### 决 / 法定（Fiat）→ 只在原生期

独占资源必须是**以低于公允价格获得**的。而**起飞之后，资源的价值就被广泛知晓了**，被显著低估的概率大幅下降。窗口自动关闭。

### 迟滞（Hysteresis）→ 只在稳定期

壁垒来自一个**所有玩家都要面对的结构性时间常数**。起飞期太短，那点时间不足以在这个时间常数的约束下积累出好处。

## 四、力量进程

把上面四条合起来：

```
原生 Origination  →  反向定位、独占资源
起飞 Takeoff      →  规模经济、网络经济、转换成本
稳定 Stability    →  流程效能、品牌
```

Helmer 用他在斯坦福教书七年间学生做的两百多个案例做了频次统计，**分布与理论推导一致**（有例外，但主体吻合）。

### 这张表怎么用

**正着用（对内）**：我现在处在起飞期，那么摆在面前的机会只有三个——规模经济、网络经济、转换成本。**其中任何一个，如果在这个窗口没抓住，就永远消失了。**

这是这一章最锋利的一句话。Helmer 讲英特尔时说得很直白：如果 PC 市场再往前跑一两年而英特尔没跟上，窗口就彻底关了——它会拿到一些销售额，但力量的前景会随着规模经济机会的消退而暗淡下去，最终沦为一家低毛利的电子元件公司，就像同期那些半导体同行一样。

**反着用（对外）**：一家已经进入稳定期的公司，如果在起飞期没建成规模/网络/转换成本，那么它现在**唯一还能建的是流程效能和品牌**，而这两样都需要十年级的时间。任何声称"我们正在快速建立护城河"的稳定期公司，基本可以直接怀疑。

## 五、起飞期最危险的一个错觉

Helmer 专门点出了一种"常见的假阳性"：

> 在爆发式增长阶段，公司常常表现出相当漂亮的财务数据。前景看起来一片光明，长期成功似乎已成定局。**不幸的是，如果一家公司没有建立力量，那么一旦增长放缓，竞争套利就会追上来**；基本面会回归，早期那些好看的回报会被证明只是过眼云烟。

然后是全书语气最重的一段：

> 每当一位 CEO 或 CFO 说他们很高兴看到一个财力雄厚的竞争者进入自己的市场、认为这"验证了市场"，**我都会心里一紧**。

他举的例子是 1981 年 IBM PC 发布时，苹果在《华尔街日报》登了整版广告："**Welcome, IBM. Seriously.**"

> 他们没有理解起飞阶段力量获取的本质：**你和你的竞争者正在进行一场相对规模的赛跑，而只能有一个赢家。**

这段话今天几乎可以原样搬用。**"友商入局共同把蛋糕做大""这个赛道需要更多玩家来教育市场"——在起飞期，这些话是危险的自我安慰。** 在起飞期，你和对手争的不是市场教育，是那个**只在这段时间里才以折扣价出售的东西**：份额。

## 六、几个当代业务的阶段判定（示例）

判定的目的是收敛搜索范围，不是给结论。

| 业务 | 大致阶段 | 因而只需检验 |
| --- | --- | --- |
| 前沿大模型 API | 起飞（增速远高于 40%） | 规模经济、网络经济、转换成本 |
| 中国新能源整车 | 已从起飞转入稳定（行业增速降至 20–30% 量级） | **窗口正在关闭**——没建成规模/转换成本的，之后只能靠品牌与流程 |
| 动力电池 | 稳定 | 流程效能、品牌（对 B 端表现为"降低不确定性"型品牌） |
| 白酒 | 稳定（且成熟） | 品牌、流程效能 |
| 先进制程代工 | 稳定 | 流程效能、品牌；**但其规模经济与独占资源是历史上建成的，仍在生效** |
| 人形机器人 | 原生 | 反向定位、独占资源 |
| 云计算 | 稳定 | 流程效能、品牌；**转换成本是起飞期建成的存量** |

**注意最后两行揭示的一个要点：**

> **阶段闸门管的是"新力量什么时候能建立"，不是"已有力量什么时候失效"。**

一家稳定期的公司完全可以靠起飞期建成的规模经济活得很好——英特尔的三种力量都建于起飞期，一直用到稳定期，这正是它市值长期坚挺的原因。闸门约束的是**新增**，不是**存量**。

**存量什么时候失效，是原书没讲的问题**，见第 11 章。

## 七、这一章在流程里的位置

```
① 业务切分        公司 → 战略独立业务
② 阶段判定    ←   本章。算业务单位增速，定阶段
③ 候选收敛        七种 → 两到三种
④ 竞争者枚举      现有 + 潜在 + 功能性
⑤ 逐力检验        候选力量 × 每个竞争者，先看壁垒
```

**第 ② 步做错，后面全错**，而且错得很隐蔽——因为你会在一个窗口已经关闭的地方，认真地找一种不可能存在的力量，并且大概率能"找到"（因为好处遍地都是）。
