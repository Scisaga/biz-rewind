## 这次改造的核心判断

原书的形态是：**故事（八成）→ 概念 → 附录公式（一成，几乎没人看）**。

这个配比在 2016 年是对的：案例是给人脑用的压缩编码，而附录里的判据算一次要人肉翻财报、找份额、估固定成本，成本太高，没人算。

**今天两件事都反过来了。** 案例已是公共知识，复述不产生新信息；而那些判据是全书唯一**能真正算出来**的部分，算它的成本已趋近于零。

> **作者为了显得严谨而写进附录的部分，恰恰是 AI 时代唯一能自动跑的部分。**

所以重写的方向是**把书倒过来**：

```
散文  → 压成决策树
公式  → 展开成测量层
案例  → 降级为校准样例（每种力量一正一反）
```

具体保留了什么、删掉了什么、为什么，见 [方法论/01-重构思路-讨论纪要.md](方法论/01-重构思路-讨论纪要.md)。

## 三处对原书结构的改动

**一、把"力量进程"从第 9 章提到第 2 章。**
它是**剪枝规则**——先定阶段，候选力量只剩两三种。真实分析中它是第一步，不是最后一步。

**二、七种力量按窗口期重排，不按原书顺序。**
原生（反向定位、独占资源）→ 起飞（规模、网络、转换成本）→ 稳定（品牌、流程效能）。这个顺序与实际使用顺序一致。

**三、增加两章原书没有的内容。**
- **第 11 章 力量的崩塌**：原书只讲如何建立力量，几乎不讲如何发现它正在破。对分析者而言这是最常需要的判断。
- **第 12 章 AI 时代的重估**：七种力量并排放着看，方向性才出得来。

## 每章的固定结构

```
一句话定义
判据：先看壁垒       ← 可算的指标、取数口径、一票否决条件
当代正例
当代反例             ← 原书没有，最值钱的一节
常见误判
衰减信号
AI 时代的重估
速查卡
```

**"当代反例"是判断一个框架是否被真正掌握的标准**：正例满地都是，能准确说出**什么不算**才是掌握。

### 第一轮回测的主要产出

**3 处结构性修改：**
- ★ **新增功能性替代扫描**——判据表原本对"整条路径被绕开"完全盲视，两个样本在崩塌前逐项检查全部"成立"、份额甚至仍在上升
- 外挂否决项从 1 条扩为 2 条（新增财务结构风险）
- 多力量叠加时禁止重复计入 `m`

**5 处阈值修订：**
- 规模／网络经济：改用 **SLM 单一阈值**（<5% 不成立），不再对两个因子分别设门槛——它们是相乘关系
- 固定成本 C 改为 **"必须自建的固定成本"**（可租用的不产生规模差）
- 流程效能：**≥5 年且跨越一个完整下行周期**，取代纯 8–10 年门槛
- 网络经济：**多宿主升为第五个正式变量**，可单项否决
- 反向定位：**二档改三档**（成立／正在失效／不成立）+ 强制输出 δ 方向

**判据表中标注【拟定】的阈值仍是本项目的假设，不是原书结论。** 第一轮把它们从"凭感觉设的数"变成了"方向经过 20 个案例检查的数"，**精确取值仍需接上真实数据后重跑。**
