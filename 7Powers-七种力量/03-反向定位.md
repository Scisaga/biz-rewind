# 第 3 章　反向定位

> **窗口期：原生　壁垒机制：附带损害**

> 新进入者采用一种更优的商业模式，而在位者**算过账之后，理性地选择不跟**。

---

## 一、这不是"在位者太蠢"

反向定位是七种力量里最容易被误解的一种，因为它的表象看起来像是在位者犯了低级错误。

Helmer 特意花了很长篇幅纠正这一点：

> 常常有旁观者天真地指责在位者缺乏远见，甚至纯粹是管理不善。这种指责往往落在那些此前因商业才干而广受赞誉的公司头上。**在很多情况下，这种看法既不公正也有误导性。在位者之所以不回应，多数时候是深思熟虑的计算结果。** 他们观察这个新模式，然后问自己："我是守住现在的路线更好，还是采纳新模式更好？"反向定位适用的，是那些答案为"不"的子集。

**这就是壁垒所在，Helmer 把它命名为"附带损害"（Collateral Damage）。**

在位者不是看不见，是**看见了，算过了，然后选择不动**——因为动了以后自己受的伤，比不动更重。

**这也是为什么它是一种力量而不是运气：** 在位者的不作为是**结构性的、可预测的、可持续的**，不依赖于对手继续犯错。

Helmer 用一句话概括了这种结构性：

> 对挑战者来说，唯一值得下的注是那种**即使在位者拿出最好的表现，它也仍然会被赶下牌桌**的注。

**这条标准把反向定位和"趁对手犯错"彻底分开了。** 商业竞争持续时间长、各方都很用心，在位者一时的疏忽不构成足够的开口——**能被利用的必须是它的结构，而不是它的失误。** 而反向定位利用的恰恰是在位者的**强项**：正是那块赚钱的旧业务，构成了它自己不敢动的壁垒。

### 一个容易被忽略的结构差异：反向定位不是排他的

规模经济与网络经济是**排他**的力量——竞争位置那一项决定了**只能有一家**处在有利位置。反向定位不同：

> 反向定位不是排他性的力量来源……相反，**相对于同一个在位者，可以有、而且事实上常常有很多个反向定位的挑战者。**

对分析的含义：**看到赛道上挤满了采用同一种新模式的挑战者，不能据此判定反向定位不成立。** 它们可以同时相对在位者拥有这项力量，然后在**彼此之间**用别的力量分胜负——而那通常就是起飞期的规模、网络与转换成本。

**这是"反向定位只是入场券"的结构性原因。**

## 二、判据：三段式，缺一不可

```
① 新模式确实更优         成本更低 和/或 可卖更高价 —— 要能算出来
② 在位者若跟进会自伤     自我蚕食率 δ 高，跟进后净利润变化为负
③ 在位者实际上没跟       且理由是"算过账"，不是"没看见"
```

**先看第 ②③ 条，那是壁垒。第 ① 条是好处，最后看。**

### 第 ③ 条是可查证的，这是反向定位最好的一点

其他六种力量的壁垒多少需要推断，反向定位的壁垒**留下公开痕迹**：

| 证据 | 在哪找 |
| --- | --- |
| 管理层对新模式的公开表态 | 业绩说明会问答、访谈、年报"管理层讨论" |
| 产品线是否调整 | 公告、新品发布 |
| 资本开支方向 | 现金流量表、投资公告 |
| 渠道政策是否变化 | 经销商大会、公告 |
| 组织调整（有没有为新模式单设主体） | 人事公告、子公司设立 |

**在位者嘴上说"我们高度关注"而资本开支毫无变化，是最强的成立信号。**

### 反向定位的五个阶段

Helmer 观察到，在位者面对反向定位挑战时有一个反复出现的剧本，他半开玩笑地称之为**反向定位的五个阶段**：

```
① 否认 Denial
② 嘲讽 Ridicule
③ 恐惧 Fear
④ 愤怒 Anger
⑤ 投降 Capitulation —— 而且常常太迟
```

**这个阶梯的价值在于它完全可观测。** 在位者管理层的公开表态几乎总能被定位到某一级上，而级别本身就是壁垒强度的读数：

| 阶段 | 典型表述 | 壁垒状态 |
| --- | --- | --- |
| 否认 | "我们没有看到这种模式对我们造成影响" | 最强 |
| 嘲讽 | "那不是真正的生意""那种打法不可持续" | 很强 |
| 恐惧 | 开始密集提及对手、成立专项小组 | 仍强 |
| 愤怒 | 内部信、公开批评、报复性价格战 | 开始松动 |
| 投降 | 正式转型 | **结束，且常已太迟** |

Helmer 自己举的例子是诺基亚。2011 年那封著名的"燃烧的平台"内部信——"当竞争者往我们的市场份额上浇火焰的时候，诺基亚在做什么？我们落后了，错过了大趋势，失去了时间……第一代 iPhone 2007 年就出货了，我们至今还没有接近那种体验的产品"——**Helmer 把它定位在"愤怒"这一级**。到 2014 年，诺基亚已从智能手机市场消失。

### "浅尝辄止"不等于跟进

这是判定第 ③ 条时最容易出错的地方，Helmer 专门给了它一个名字：

> 一旦份额侵蚀变得严重，被反向定位的在位者就会承受巨大的"必须做点什么"的压力；与此同时，他们又承受着不能打翻旧模式这只苹果车的压力。这种二元性的常见结果，不妨称之为**浅尝辄止（dabbling）**：在位者以某种方式把脚趾伸进水里，**但拒绝以任何真正回应挑战的方式投入**。

**所以一票否决的正确表述不是"在位者模仿了"，而是"在位者做出了实质性承诺"。** 判定应落在**资源投入**上，而不是产品是否存在：

| 现象 | 判定 |
| --- | --- |
| 上线了对标产品，但资源、定价权、渠道政策照旧 | **浅尝辄止 → 反向定位仍然成立** |
| 独立主体、独立考核、核心资源倾斜、明确接受主业受损 | **实质跟进 → 反向定位不成立** |

### 一份现成的联合观察清单

Helmer 列出了反向定位通常伴随出现的一组现象，可以直接当核对表：

```
挑战者一侧：  份额快速上升
              盈利能力强（或至少有明确的盈利前景）

在位者一侧：  份额流失
              无力反制对手的动作
              最终出现管理层动荡
              投降，而且常常太迟
```

**在位者那四项征兆同时出现时，反向定位的成立概率很高。**

### 需要算的量：自我蚕食率 δ

在位者跟进新模式时，新业务会吃掉多少旧业务。

```
δ 越高  →  在位者跟进的损失越大  →  它越不会跟  →  壁垒越强
```

Helmer 用剩余领导者利润率（SLM）刻画这件事，结论是：**如果 SLM = 0，反向定位就不存在。**

粗略的取数方式：
```
受威胁业务收入 / 在位者总收入        → 暴露度
受威胁业务的毛利率 vs 新模式毛利率    → 单位损失
在位者的固定成本结构（渠道、门店、人员）→ 转不动的部分有多重
```

**渠道和人员是最常见的"转不动的部分"。** 一家靠数万家经销商卖货的公司要转直营，损失的不只是利润率，是整个分销体系的忠诚度。

## 三、当代正例

### 拼多多 vs 传统电商平台

**新模式**：白牌 + 极致低价 + 社交裂变获客 + 平台低佣金/低门槛招商，绕开搜索广告竞价这套变现机制。

**在位者为什么难跟**：主流电商平台的核心收入结构建立在**品牌商家的广告投放与佣金**上。全面拥抱白牌与极致低价，等于压低自己客单价、稀释品牌商家的展示权重、动摇广告竞价体系——**自我蚕食率极高**。

这不是没看见。在位者很早就做了对标产品，但**在集团内部，它无法获得会伤害主业的资源与政策力度**——这正是附带损害的典型形态：不是不能建，是**建了不能真打**。

**注意壁垒随时间衰减**：随着在位者主业增速放缓、低价心智被市场普遍接受，δ 在下降，在位者的跟进意愿在上升。这条力量正在变弱，符合下面第六节讲的规律。

### Costco 的会员制

**新模式**：商品毛利压到极低（远低于常规零售），利润主要来自会员费；SKU 数量极度精简以获得单品采购规模。

**在位者为什么难跟**：一家常规超市要转会员制，得先把商品毛利砍掉一大半，然后指望会员费补回来。**过渡期的利润表是灾难性的**，而会员规模需要多年才能积累到位。对上市公司来说，这个转型的账在董事会上过不去。

这是一个**已经运行了几十年、至今没被有效模仿**的反向定位。它的寿命之长，来自于附带损害在这个模式里是**结构性的、不随时间减弱的**。

### 开源权重模型 vs 闭源 API

**新模式**：把模型权重公开发布，靠云服务、企业部署或生态位变现，而不是按 token 收费。

**在位者为什么难跟**：一家核心收入来自 API 调用的公司，公开发布同代能力的权重，等于直接把自己的收入基础拿掉。**δ 接近 1。**

这是反向定位在 AI 时代最清晰的一个实例，而且它同时演示了**这种力量的两个典型特征**：
- 在位者的应对不是模仿，而是**换战场**（往更强的前沿模型、往应用层、往企业服务走）——这是被反向定位命中的在位者最常见的正确反应；
- 挑战者的收益不一定体现在利润率 `m` 上，可能体现在份额 `s`、生态位或战略选择权上。

**Vanguard 也是如此**——它把好处全部返还给基金持有人，兑现的是 `s`（份额），而不是 `m`。Helmer 明确指出了这一点。**看不到利润率提升就说没有力量，是误读。**

## 四、当代反例：在位者跟了，而且跟成了

**这一节比上面那节重要。**

### 微软的云与订阅转型

微软曾经是被反向定位命中的教科书对象：本地授权、装机绑定、按版本收费——面对云与订阅模式，δ 极高。

**然后它跟了，而且跟成了。** 从 Windows 中心转向云与订阅优先，接受了对本地授权收入的自我蚕食。

**结论：对微软的反向定位不成立。** 不是理论错了，是第 ③ 条的事实变了——在位者实际跟进，且没有受到实质损害。

### Adobe 的订阅制转型

从盒装授权转向订阅，同样是主动自我蚕食：短期收入确认方式的改变让报表难看了一段时间，公司顶住了。

**这两个案例给出了反向定位最重要的一票否决：**

> **在位者做出了实质性承诺（不是浅尝辄止），且没有受到实质损害 → 反向定位立即不成立。**

不需要再算 δ，不需要再看模式优劣。这一条直接出局。

**注意"实质性承诺"这个限定。** 微软与 Adobe 都是把主业收入基础主动交出去的转型，不是上线一个对标产品。**判定的分界线是：它有没有接受旧业务受损。**

### 部分被跟进的情形

零佣金券商曾对传统券商构成反向定位——佣金是在位者的重要收入来源，砍掉它是明显的自伤。但在位者最终**还是跟了**，因为它们发现可以靠其他方式（利息、资管、投顾）补回来。

**这揭示了一个判断要点**：δ 高不等于在位者不能跟，还要看它**有没有替代的变现通道**。有，则可能跟；没有，才是真壁垒。

**检验时必须多问一句：在位者跟进后，它旧模式里那块收入，有没有别的地方可以补回来？**

## 五、常见误判

| 误判 | 为什么错 |
| --- | --- |
| **"我们的模式更先进，所以有反向定位"** | 模式更优只是好处。**壁垒在于在位者不跟。** 在位者跟了，模式再先进也没有力量 |
| **把在位者的迟缓当成结构性不作为** | 迟缓两年是执行问题，会被纠正；结构性不作为才是壁垒。**区分方法：问它跟进后损失多少，损失能不能补回来** |
| **忽略在位者可以"不对称跟进"** | 在位者可以另起品牌、另设主体、只在特定市场跟。这会显著削弱壁垒 |
| **把"补贴换份额"当反向定位** | 补贴不是商业模式，在位者也能补。**必须是结构性的成本或定价优势** |
| **认为反向定位是永久的** | 见下一节。**这是七种力量里最会过期的一种** |

## 六、衰减：这是七种力量里最会过期的一种

原书对力量衰减几乎没有系统论述，**唯一的例外就在这里**，因此格外值得记住：

> 由于 δ 趋于下降，SLM 随之下降，附带损害随之减弱。

机制很简单：在位者的旧业务本身在萎缩。当那块业务已经从占收入 70% 掉到占 20% 时，跟进的边际损失就小得多了——**它终于跟得起了。**

于是反向定位有一个**自带的到期日**：

```
δ 下降  →  在位者跟进的损失变小  →  它开始跟  →  力量消失
```

**实践含义（很重要）：**

> 任何一条反向定位的结论，都必须带**有效期**，并定期重估 δ。

它不像品牌或流程效能那样越老越强，而是**越老越弱**。这也解释了为什么很多靠反向定位起家的公司，必须在窗口关闭之前把利润再投到起飞期的三种力量上——**反向定位是入场券，不是终点。**

**Vanguard 是罕见的例外**：它的模式让在位者永远跟不起（跟进就要放弃主动管理的高费率），而它自身的规模又持续压低成本，**把反向定位换成了规模经济**。这才是完整的路径。

## 七、AI 时代的重估

**方向：变强，但寿命更短。**

- **变强**：AI 让"新模式的成本优势"可以做得比过去大得多。用极小团队 + AI 交付过去需要数百人交付的服务，对一个人力密集的在位者来说，δ 是毁灭性的——它的成本结构就是它的人员。人力密集型服务业（法务、咨询、审计、外包、客服、部分医疗与教育）正在成为反向定位的密集发生区。
- **寿命更短**：AI 同样降低了在位者跟进的技术门槛。过去在位者跟不上是因为"做不出来"，现在多半只剩"不敢做"。**一旦它敢了，就跟得很快。**

**重估的操作含义：** 对 AI 驱动的反向定位，把默认有效期**调短**，并把"在位者的组织包袱（人员、渠道、既有合同）"作为壁垒强度的主要变量——因为技术包袱正在快速消失，只剩组织包袱了。
