# 第 11 章　力量的崩塌：原书没写的那一半

> **本章是原创补充。** 原书讲的是力量如何**建立**，几乎不讲如何发现它**正在破**。

---

## 一、缺的是什么

《7 Powers》从头到尾是一本**建设者视角**的书。它回答两个问题：我该做什么（第 10 章）、什么时候能做（第 2 章）。这对创业者和管理者是对的。

但对**分析者和投资者**来说，最常需要的判断是另一个：

> **这家公司的力量，还在吗？还能维持多久？什么信号出现时我该改变结论？**

原书对此几乎没有系统论述。全书唯一一处明确的衰减机制在反向定位那一章——自我蚕食率 δ 随时间下降，附带损害随之减弱。**这一处例外恰恰说明其余六种也应该有各自的衰减机制，只是作者没有写。**

这一章把它补上。

**这也是把这本书变成一个可持续使用的工具的关键。** 一次性的判定只能用一次；带衰减模型的判定可以一直用下去。

## 二、从壁垒机制推出死法

方法上，不必为七种力量各编一套衰减理论。原书已经给出了更经济的结构：**七种力量只有四种壁垒机制**。壁垒怎么死，力量就怎么死。

| 壁垒机制 | 涉及的力量 | 它的死法 |
| --- | --- | --- |
| **抢份额成本** | 规模经济、网络经济、转换成本 | 份额突然变得**便宜**了 |
| **附带损害** | 反向定位 | 在位者的**自伤变小了** |
| **决 / 法定** | 独占资源 | 裁定**到期或改变** |
| **迟滞** | 品牌、流程效能 | **时间常数缩短了** |

这四句话就是全部。下面把它们各自展开成可观测的信号。

### 抢份额成本型的死法：份额变便宜

三种典型路径：

1. **技术路线切换**——新进入者不需要追平你的旧规模。**这是最凶险的一种，因为不是被追上，是被作废。** 英特尔在存储上就是这样输的。
2. **固定成本被外部化**——当第三方开始对外提供原本必须自建的能力（代工、云、共享产能），行业整体的规模经济强度（SLM 第一项）会下降，**因为所有人都能租到规模**。
3. **网络的必要性被绕开**——不是有人建了更大的网，是**用户不再需要那张网**。

### 附带损害型的死法：在位者终于跟得起了

机制见第 3 章。旧业务萎缩到一定程度，δ 自然下降，跟进的边际损失变小。

**这是唯一一种"自带到期日"的力量。**

### 决型的死法：日历上写着

专利到期、牌照续期、长约到期、法规变更、关键人离职。

**这是七种里唯一可以提前很多年精确预知失效时点的一种。** 应当直接建成一张到期日历。

### 迟滞型的死法：时间常数缩短

壁垒的强度**等于**那个时间常数。所以：

- **品牌**：当验证质量变便宜、当分发从"你记得哪个"变成"系统推荐哪个"，建立信任所需的时间在缩短
- **流程效能**：当默会知识可以被观测、记录、重现，"十年追不上"可能变成"三年追得上"

**时间常数一缩短，壁垒就不成立了——这不是变弱，是消失。**

## 三、六种崩塌模式

从上面的机制里，可以归纳出六种在现实中反复出现的形态。**判定一条力量正在崩塌时，先确定它属于哪一种，因为每一种的先行指标不同。**

### 模式一：被追平

对手用同样的路子做到了同等水平。**最慢、最容易看见、也最不致命**的一种。

**先行指标**：龙头与追随者的相对指标（规模比、良率差、价差）持续收窄。

### 模式二：被绕开

需求还在，但满足需求的路径变了，你的壁垒建在一条不再有人走的路上。

**这是最快、最彻底、也最容易被漏掉的一种**，因为它来自你的竞争者名单之外——正是第 1 章讲的**功能性替代者**那一格。

在线作业辅导公司被通用助手取代、问答社区的流量被直接问答取代——这些都不是输给了同行。**它们的护城河一直好好的，只是护城河外面的城不见了。**

**先行指标**：**用户行为的替代**，而不是份额的转移。要盯的是"完成同一件事的人里，有多少不再用你这条路径"，而不是"你的市场份额是多少"。**份额数据在这种崩塌里会骗人——因为你在一个正在消失的市场里份额还在上升。**

### 模式三：被作废

技术路线切换，你的资产从壁垒变成包袱。

**特征是资产负债表先于利润表出问题**：产能利用率、资产减值、折旧压力。

**先行指标**：新增订单的技术规格开始偏离你的产能结构。**这通常比收入下滑早两到三年出现。**

### 模式四：被自毁

**七种力量里，品牌是唯一可能被自己人的增长指标破坏的一种**（见第 8 章的稀释机制）。流程效能也有类似风险——为了短期成本目标砍掉长期投入。

**先行指标**：管理层的动作而不是市场的数据。渠道政策放松、品类向下延伸、授权扩张、长期投入被砍。**这些在公告和经营动作里看得见，比财务指标早很多。**

### 模式五：被上下游挤走

力量还在，但赚的钱被产业链的其他环节拿走了。

**Helmer 主动把这块排除在 7 Powers 之外**（他认为供应商与买方议价属于波特五力的范畴，而 7 Powers 只讲竞争者之间的套利）。**但这是一个真实且常见的价值杀手，必须外挂补上。**

典型形态：一家在自己环节里有很强规模经济和用户网络的公司，其核心投入品由极少数供应商控制，于是收入增长的大部分转化成了内容成本、算力成本或原料成本。**它在自己的战场上赢了，钱却被上游拿走了。**

**先行指标**：收入增长与毛利率的背离——**规模在涨，单位经济性不改善**。

---

### 模式六：被反向定位

在位者的力量被一个采用异端商业模式的挑战者瓦解。**它值得单列，因为它是六种模式里唯一有一份公开的、逐级可读的早期预警表。**

Helmer 的"反向定位五阶段"（第 3 章）本来是写给挑战者看的，但**反过来读，它就是在位者力量崩塌的进度条**：

```
否认 → 嘲讽 → 恐惧 → 愤怒 → 投降（常已太迟）
```

配合他给出的在位者征兆清单——份额流失、无力反制、管理层动荡、投降太迟——**这是唯一一种可以从管理层的嘴里读出进度的崩塌。**

Helmer 自己举的例子是诺基亚，并把 2011 年那封"燃烧的平台"内部信定位在"愤怒"级。**从愤怒到消失，用了三年。**

**先行指标**：在位者公开表态的阶段位移。**注意方向——它是从"没影响"往"这不公平"移动，而不是财务数据先动。**

## 四、别把经营失误当力量崩塌

在讨论指标之前，必须先立一条纪律，否则会把所有噪声都读成信号。

Helmer 在 Netflix 那一章里专门处理过这件事：

> 我一直谨慎地把力量描述为**创造价值的潜力**，而这个潜力只有在与经营卓越结合时才能被实现。**Netflix 在 2011 年的暴跌是经营失误的结果。** 尽管那段时期很痛苦，但它们的战略依然有效、力量完好无损，所以这些失误并不致命。

**判别方法：**

| | 经营失误 | 力量崩塌 |
| --- | --- | --- |
| 壁垒本身 | 没变 | 变了 |
| 相对指标（份额比、良率差、价差） | 通常不变 | **持续朝一个方向走** |
| 可逆性 | 换个做法就能恢复 | 不可逆 |
| 竞争者的处境 | 也没有变好 | **变好了** |

**最好用的一条：看竞争者。** 如果你出问题的同时对手并没有变得更强，那多半是经营失误；如果对手的相对位置系统性改善了，那是力量在破。

Helmer 还给了一条与此相关的、对读数据的人极重要的提醒：

> **在高通量的情形下，现金流往往需要时间才能可靠地反映力量**，因此投资者的预期会上下波动。

**这正是下一节的理论依据：现金流是力量的滞后、且带噪声的投影。**

## 五、指标的先后顺序

这一节可能是整章最实用的部分。

**利润率是最滞后的指标。** 等到 `m` 开始下滑，力量通常已经破了两三年。原因很简单：企业会用各种方式护住利润表（削减投入、提价、优化结构），而这些动作本身就是崩塌的症状。

**按先后排序：**

```
最早  ①  经营动作与合同条款          管理层在做什么，客户在合同里要求什么
      ②  相对指标                    份额比、良率差、价差、留存差
      ③  单位经济性                  单客户收入、单位成本、获客成本
      ④  增长结构                    新客户 vs 存量、新品类中标率
最晚  ⑤  利润率                      m
```

**几个具体的早期信号，价值远超其在报表上的位置：**

| 信号 | 说明的是 |
| --- | --- |
| 大客户在续约时要求锁价、免费扩容、迁移条款 | **转换成本已被客户公开定价**，Δ 在缩水 |
| 存量客户对**新品类**的中标率下降 | 关系型转换成本在减弱（第 7 章：**最早的信号**） |
| 促销季价差保持率下降 | 品牌溢价在瓦解 |
| 销售费用率上升而溢价不变 | 品牌在输血维持 |
| 设备供应商开始把 know-how 打包销售 | 流程效能的不透明性在消失 |
| 在位者的资本开支方向首次改变 | 反向定位的 δ 已经降到它跟得起了 |
| 年轻客群的溢价支付意愿显著低于存量客群 | 品牌在下一代人身上没有重建（最慢但最致命） |

## 六、一个完整的崩塌样本

英特尔既是原书的正面案例，也是当代最完整的崩塌样本，而且**它是两种模式同时发生**：

- **流程效能**：先进制程的工艺领先曾经是典型的迟滞型壁垒——复杂、不透明、对手多年追不上。当这个相对优势被反转，壁垒不是变弱，是**归零**（迟滞型壁垒的特点就是：一旦时间常数不再对你有利，它立刻站到对手那边）。
- **规模经济**：当代工模式让设计公司可以**租用**先进产能，"必须自建晶圆厂"这个巨额固定成本不再是所有人的门槛（模式一 + 固定成本外部化）。

**它的教训在于时序**：这个过程中有很多年，财务数据仍然很好看。**利润率是最后崩的。** 而早期信号——制程节点的时间表一再推迟、大客户开始把订单分给别人、新架构的设计导入率下降——出现得早得多。

**如果只看 `m`，你会在最后两年才知道。**

## 七、力量的叠加与顺序

原书箴言里那个"**continuing**（持续）"，Helmer 说是特意加的，用意是提醒**随着业务发展要不断叠加新的力量来源**。

结合第 2 章的窗口，这句话有了非常具体的操作含义：

```
原生期：反向定位 / 独占资源     ← 入场券，且反向定位自带到期日
   ↓  必须在窗口关闭前换成 ↓
起飞期：规模 / 网络 / 转换成本   ← 主力，一旦错过永远消失
   ↓  长期经营才可能叠加 ↓
稳定期：品牌 / 流程效能         ← 最耐久，但需要十年级时间
```

**一家公司的力量结构是不是健康，看的是它有没有在窗口关闭前完成这几次转换。**

- 只有原生期力量、没能在起飞期换挡的公司，会在增速放缓时迅速失去超额利润——**这是最常见的死法，而且死得很突然**，因为反向定位的失效是断崖式的（在位者从"不跟"变成"跟"是一个开关，不是一条曲线）。
- 有起飞期力量、但从未建立稳定期力量的公司，能撑很久，但一次技术路线切换就可能归零。
- 三层都有的公司极少，它们就是那些看起来"怎么打都打不死"的公司。

**这个视角也给出了一个很实用的提问**：这家公司**上一次**新增力量来源是什么时候？如果答案是十年前，那它现在赚的钱全部依赖存量壁垒，而存量壁垒只会衰减。

## 八、结论必须带的三个字段

综合上面所有内容，一条力量判定如果不带这三个字段，它就是不可维护的：

```
证伪条件：   看到什么，我就推翻这个结论
有效期：     什么时候必须重估
崩塌模式：   如果它要死，最可能是六种里的哪一种（决定盯哪个先行指标）
```

**第三个字段是这一章的产出。** 它把"持续跟踪"从一件需要全面扫描的事，变成一件只需要盯几个特定指标的事。
