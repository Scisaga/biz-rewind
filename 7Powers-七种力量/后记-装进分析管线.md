# 后记　把七种力量装进分析管线

> 这本书的最终用途不是被读一遍，是**被执行很多遍**。这篇后记讲从读物到工具的最后一步。

---

## 一、先接受一条边界

Helmer 在书里亲手划了一条线，任何想把 7 Powers 变成分析工具的人都必须先接受它：

> **在绝大多数情况下，力量的潜力和市场规模，对精明的投资专业人士来说都足够明显**，常常能在历史财务数据的痕迹里找到。在这些情形下，7 Powers 不提供任何优势。

超额认知只可能出现在**不透明**、且这种不透明**可被 7 Powers 穿透**的地方；而不透明的首要来源是**高通量**——快速变化。

**推论（决定整个工具的形态）：**

> **不要做成"给全市场公司打护城河分"。** 那是把力气花在市场早已定价的地方，做出来好看，但不产生信息。

正确形态是两段式：

```
第一段（廉价，全市场）：找出正处在剧变中的业务
第二段（昂贵，少数标的）：只对它们做完整的七力检验
```

**这一条如果不接受，后面做得再精致都是白费。**

---

## 二、执行顺序

```
① 业务切分       公司 → 战略独立业务（第 1 章：分析对象是业务不是公司）
② 阶段闸门       业务单位增速 → 原生／起飞／稳定（第 2 章）→ 候选收敛到两三种
③ 功能性替代扫描 ★ 客户要完成的那件事，还走不走我们这条路径（第 11 章"被绕开"）
④ 竞争者枚举     现有 + 潜在 + 功能性替代者（第 1 章）
⑤ 逐力检验       候选力量 × 每个竞争者，先看壁垒，再看好处
⑥ 3S 闸门        Superior / Significant / Sustainable
⑦ 价值映射       填 M0·g·s·m，指定主导力量，与市价隐含的 m 对比
⑧ 外挂否决项     上下游议价挤压 / 财务结构风险（可否决，不可新增力量）
⑨ 派生监控       每条成立的结论输出证伪触发器（第 11 章）
```

**这个顺序不是设计出来的，是回测出来的**（[方法论/04](方法论/04-判据回测与阈值校准.md)）：② 以极低成本独立拦下了 2/7 个伪力量样本；⑤ 内部的两台主力筛子（网络经济 δ、规模经济 C 口径）合计拦下 5/7。

**三个最容易被跳过、跳过后代价最大的步骤：**

**① 业务切分。** 跳过它，结论会被稀释成一家公司的平均值，而平均值没有意义。多元化公司里通常只有一块业务真正有力量。

**③ 功能性替代扫描。** 这是判据表在第一轮回测中**唯一完全失手的地方**——两个案例在崩塌前逐项检查全部"成立"，市场份额甚至还在上升。它是"被绕开"型崩塌的唯一入口。

**⑤ 里的"先看壁垒"。** 顺序反了，你会得到一份非常好看、每句都对、但完全没有信息量的报告。

## 三、输出的形态

**不是评分，是矩阵。**

```
业务：      <战略独立业务名>
阶段：      起飞（依据：单位增速 XX%）
候选力量：  规模经济 / 网络经济 / 转换成本

            规模经济    网络经济    转换成本
对手 A      成立        不成立      证据不足
潜在 B      不成立      不成立      不成立
替代 C      —           —           —
```

**每一格都要能展开成：**

```
壁垒：      成立 / 不成立 / 证据不足      ← 先判这个
好处：      具体机制
指标：      名称与数值
3S：        superior / significant / sustainable
证据：      出处清单
置信度：    高 / 中 / 低
证伪条件：  看到什么就推翻
崩塌模式：  五种里的哪一种（决定盯哪个先行指标）
有效期：    何时必须重估
```

**"证据不足"是一个合法且值得鼓励的结论。** 它比编一个理由有价值得多——因为它准确地标出了下一步该去查什么。

**最后三个字段是把一次性判断变成可持续跟踪的关键。** 没有它们，报告写完就死了。

---

## 四、为什么必须是结构化的、可比对的

因为力量的价值信息**几乎全在变化里**，而不在水平里。

一条"规模经济成立"的结论，本身市场大概率已经知道了。有信息量的是：

> **上季判定成立，SLM 从 12% 降到 7%，触发降级。**

这需要两个条件：结论是结构化记录的，且历史版本可比对。

**报告是渲染出来的副产品，结构化记录才是真源。** 这个顺序如果反了，就只剩一堆无法互相比较的文档。

---

## 五、这本书最耐用的部分

如果这套东西最终要压缩成几句能一直用下去的话，我会选这几条：

**一、永远先看壁垒。**
好处遍地都是，壁垒才稀缺。这一条同时是最好的反自欺装置——它把"编一个理由"换成了"找出对手为什么追不上"，而后者经常失败，失败的时候恰恰是你最该知道的时候。

**二、分析对象是业务，不是公司。**
英特尔的存储与微处理器，同一批人、同样的卓越经营，0 与 1500 亿。

**三、先定阶段，再找力量。**
七种砍到三种。而且砍掉的不是省略，是排除——它们在这个阶段不可能存在。

**四、力量是成对的，结论是矩阵。**
一个套利者就够了。而最危险的那个，通常不在你的竞争者名单上。

**五、"重大"要单独问一遍。**
能不能折算成 `m` 的几个百分点？答不上来，就归到"经营优秀"，不进战略结论。

**六、四种壁垒机制才是引擎，七种力量只是结论。**
拿壁垒机制去对照任何一次技术或制度变迁，问它改变了哪一种。这个动作对下一次变迁同样有效。

**七、`m` 是最滞后的指标。**
等它下滑，力量通常已经破了两三年。

## 六、还没做的事

**已完成**：判据规格 v2（[方法论/02](方法论/02-判据表-七力可执行规格.md)）、管线设计（[方法论/03](方法论/03-分析管线架构.md)）、**第一轮回测校准**（[方法论/04](方法论/04-判据回测与阈值校准.md)）、本书。

**第一轮回测（20 个样本）产出了 3 处结构性修改和 5 处阈值修订**，其中最重要的一处不是数字调整，而是发现判据表少了一步：它对"整条路径被绕开"完全盲视——两个案例在崩塌前逐项检查全部"成立"。

**下一步（第二轮回测）要纠正本轮样本的两个偏差：**

1. **负样本集中在消费互联网**。制造业、B 端软件、医药、周期品的伪力量样本几乎没有，而这几类的失败模式很可能不同。
2. **没有假阴性样本**——即"当时看起来不像有力量、后来证明有"的案例。本轮 6 个正例全部通过，说明没有误杀，但也可能只是样本选得太典型。**这类样本能检验判据表是不是过严。**

**回测的目的从来不是验证框架对不对**（它已被四百多个案例验证过），**而是校准我们自己填进去的那些数字与顺序**。经过第一轮，它们从"凭感觉设的数"变成了"方向经过 20 个案例检查的数"——**但仍然是【拟定】，精确取值必须等接上真实数据后重跑。**

## 七、最后

Helmer 说，如果全书只带走一句话，他希望是箴言：

> **在有意义的市场中通往持续 Power 的路径。**

这句话之所以耐用，是因为它的每个词都是一道检验，而且四道检验合起来，恰好穷尽了企业价值的全部来源。它没有多余的东西，也不缺东西。

**这本书最好的部分，是它敢于把范围划得很窄。**

作者主动放弃了组织、文化、领导力、营销、执行——不是因为它们不重要（他明确说过，没有经营卓越，一切潜在价值都无法兑现），而是因为**把范围划窄，才换来了可判定性**。

而可判定性，正是一套方法论能不能交给机器执行的前提。

这也是为什么，一本 2016 年写给企业家的书，在今天反而更该被认真对待。**它的散文部分正在贬值，它的判据部分正在升值。**
