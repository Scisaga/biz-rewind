# 第 5 章　规模经济

> **窗口期：起飞　壁垒机制：抢份额成本**

> 单位成本随业务规模下降，且龙头与追随者之间存在难以逾越的规模差。

---

## 一、这一章是全书唯一能算得干干净净的一章

七种力量里，规模经济的判据最接近"可以直接用财报算出来"。所以这一章的重点不是讲道理，是**把算法交代清楚**。

Helmer 的提问方式很聪明。他不问"规模优势有多大"，而问：

> **当价格被压到无力量的弱者利润为零时，有力量的强者还能保有多少利润率？**

他把这个数叫做**剩余领导者利润率（Surplus Leader Margin, SLM）**。

这个提法的高明之处在于，它同时衡量了两件事：**赚钱的能力**，和**必要时打价格战保份额的余地**。后者才是壁垒的实质——追随者不来攻，不是因为攻不动，而是因为**它算过，攻的收益不划算**。

---

## 二、判据

对固定成本型的规模经济：

```
SLM = [ C / R_龙头 ] × [ R_龙头 / R_追随者 − 1 ]
       └─ 规模经济强度 ─┘  └──── 规模优势 ────┘

C ≡ 固定成本（不随销量变化的那部分）
R ≡ 收入
```

**两项都必须显著为正。** Helmer 特别举例说明：即使潜在的规模经济很强（C 相对收入很大），只要没有规模差距，第二项为零，**领导者的剩余利润率也是零——没有力量**。

反过来也一样：你的规模是对手的五倍，但这个行业本来就没什么固定成本，第一项接近零，**力量还是零**。

### 这个分解为什么重要

它把力量拆成了**行业的**和**你的**两部分，而这对应两类完全不同的战略动作：

| | 是什么 | 怎么改 |
| --- | --- | --- |
| 第一项 | 行业经济结构 | **改变行业的成本结构本身** |
| 第二项 | 你的相对位置 | 抢份额 |

Helmer 用 Netflix 说明了两者可以同时做：转向独家与自制内容，**把内容从"人人可比价采购的商品"变成"巨额固定成本"**（改变第一项），同时早期投入抢下规模优势（改善第二项）。

他给了一句很重的话：**如果 Netflix 接受当时的行业经济结构不变，流媒体这条路上根本不存在通往力量的路径**，它的价值前景会一直暗淡地依附在那个正在衰退的 DVD 租赁业务上。

**多数人只想第二列。改变第一列往往是更大的机会。**

---

## 三、规模经济的五个来源

判定之前要先确定面对的是哪一种，因为取数口径完全不同。原书在固定成本之外还列了四种：

| 来源 | 机制 | 例子 |
| --- | --- | --- |
| **固定成本摊薄** | 单笔大额固定投入被摊到更多产量上 | 内容自制、芯片研发、大模型训练 |
| **体积／面积关系** | 成本随**面积**增长，效用随**体积**增长 | 储罐、仓库、船舶、反应釜 |
| **配送网络密度** | 单位面积客户越多，路径越经济，配送成本越低 | 快递、外卖、生鲜前置仓 |
| **学习经济** | 学习带来的降本提质与**累计产量**正相关 | 良率爬坡、工艺积累 |
| **采购经济** | 大买家能拿到更好的投入品价格 | 大型零售、整车厂 |

两点提示：

**配送网络密度这一条，是"地理边界"问题的根源。** 它的规模效应发生在**单位面积**上，不是在全国总量上。原书正是用它来说明新进入者为何难以挑战一张成熟的配送网络——**而同样的逻辑意味着，一张覆盖全国但每个城市都很稀疏的网络，并不具备这项力量。**

**采购经济是五种里壁垒最弱的一种。** 它是规模经济的合法来源（原书明确列出），但它的好处很容易在供应商集中时、或在下一次合同重谈时被拿回去。**判定时应当计入，但要单独标注可持续性存疑**——它是最容易随一次谈判而消失的规模优势。

## 四、固定成本 C 怎么取

这是实操中最容易出错的地方。口径错了，整个数就废了。

| 行业 | C 的近似 | 不能算进去的 |
| --- | --- | --- |
| 半导体 / 面板 / 化工 | 折旧摊销 + 研发 | 原材料、封测代工 |
| 软件 / SaaS | 研发 + 平台运维 | 按量计费的云成本、销售提成 |
| 内容平台 | 自制内容摊销 + 版权摊销 | 带宽（近似随用量变动） |
| **大模型** | **训练算力折旧 + 研究人员薪酬** | **推理算力**（随调用量变动） |
| 连锁零售 / 餐饮 | 供应链与中央厨房折旧 + 总部费用 | **门店租金人力**（随门店数线性增长） |
| 医药 | 研发（临床开支） | 生产、销售 |
| 物流 | 干线网络与分拣中心 | 末端配送（随件量变动） |

**最常见的错误是把随规模线性增长的成本当固定成本。** 连锁业态尤其容易犯：门店多了，租金和人力等比例增长，这部分不产生规模经济。**连锁企业真正的规模经济在供应链和总部摊销，不在门店。**

## 五、当代正例

### 前沿大模型训练

这是**当代最纯粹的固定成本型规模经济**，纯粹到几乎可以当教科书插图：

- 训练一次模型的成本，与之后有多少人用它，**几乎无关**——教科书定义的固定成本
- 固定成本占收入比例极高（第一项很大）
- 推理成本随用量变动，不进 C

**但第二项要小心。** 规模优势要用**同代能力下的收入或调用量之比**来算，而不是用参数量或融资额。如果头部几家的收入在同一量级，第二项就不大，SLM 也就有限——这与"这个行业固定成本极高"并不矛盾，两项要分开看。

**这正是"两项都必须显著为正"这条规矩最有价值的地方**：它让你在一个所有人都在喊"规模就是一切"的行业里，能问出第二个问题。

### 先进制程晶圆代工

第一项：先进制程产线与研发的资本开支规模惊人，且不随出货量变化。
第二项：先进节点的产能与客户份额高度集中。

两项都很大，所以 SLM 很高，表现为**行业老二老三长期难以在先进节点上盈利**——这正是 SLM 的定义在现实中的样子：当价格被压到追随者不赚钱时，龙头仍有可观利润。

**注意它同时叠加了流程效能（良率）和独占资源（设备优先获取）。多种力量叠加是常态，但判定时要分开算，否则会重复计数。**

### 动力电池与光伏

两者都是固定成本重（产线折旧 + 研发）的行业，但**结局不同**，差别在第二项：

- 头部集中、规模差距拉得开的环节 → SLM 为正
- 产能高度分散、龙头与老二规模接近的环节 → 第二项趋近零 → **行业周期性亏损**

**这是同一个行业里第一项相同、第二项不同带来的完全不同的命运**，也是为什么"这个行业有规模经济"这句话本身不构成任何结论。

### 连锁餐饮的供应链

规模经济发生在**供应链和中央厨房**，不在门店。判定时应该用供应链相关的固定成本 / 收入作为第一项，而不是整体成本。

这类企业的规模优势通常表现为**在同等售价下毛利更高，或在同等毛利下售价更低**——后者是它们抢份额的武器，也正是 SLM 的现实形态。

## 六、当代反例

| 情形 | 为什么不是规模经济 |
| --- | --- |
| **"我们采购量大所以拿货便宜"** | **这是规模经济的合法来源（采购经济），但不能单独支撑结论**：若供应商也集中，或合同按年重谈，优势会被拿回去。**计入，但标注可持续性存疑** |
| **全国第一，但在每个区域都是第三** | **规模经济常有地理边界**。外卖、生鲜、区域连锁、水泥、区域物流都是。**边界之外没有力量** |
| **收入很大但成本几乎全是变动成本** | 第一项趋近零。人力密集的服务业、贸易、代运营多属此类 |
| **规模差距只有 10–20%** | 第二项太小。**判据看 SLM 本身**：SLM <5% 判不成立（回测校准值）。规模差 <1.3 倍且自建固定成本占比 <5% 时可直接出局 |
| **技术路线即将切换** | 旧产能的规模优势会随路线切换归零。**这是规模经济最凶险的失效方式**——不是被追平，是被作废 |

**最后一条值得展开。** 规模经济的壁垒建立在"追随者要花很多钱才能追平你的规模"之上。但如果出现一条新技术路线，让新进入者**根本不需要追平你的旧规模**，那么你的固定资产从壁垒变成了包袱。

这正是英特尔存储业务失败的机制，也是这一章最该带走的警惕。

---

## 七、衰减信号

规模经济不像品牌那样越老越强，它有明确的破裂方式：

1. **龙头 / 追随者收入倍数持续收窄** → 第二项在缩小
2. **龙头与追随者的毛利率收敛** → SLM 在现实中消失
3. **行业出现技术路线切换** → 第一项的资产基础被作废（最危险）
4. **需求侧碎片化** → 大规模标准化生产的优势让位于小批量定制
5. **固定成本被外部化** → 当有第三方开始对外提供原本必须自建的能力（代工、云、共享产能），行业的第一项会**整体下降**，因为所有人都能租到规模

**第 5 条在今天特别重要**：云计算把算力的固定成本变成了可租用的变动成本，这在很多行业里系统性削弱了规模经济。同样的事正在算力、制造、物流上发生。

## 八、AI 时代的重估

**方向：在基础设施层剧烈强化，在应用层剧烈弱化。**

**强化的**（固定成本变得极重）：
- 前沿模型训练
- 算力基础设施与配套电力
- 需要巨额资本开支的实体制造

**弱化的**（固定成本被租用化、可变化）：
- 应用层软件——过去要养一支大工程团队（固定成本），现在小团队可以交付相当的东西。**第一项在塌**
- 内容生产——单位内容成本大幅下降，"用规模摊薄制作成本"这件事的意义在下降
- 大量原本靠人力规模摊薄总部成本的服务业

**一个必须记住的推论：**

> **AI 让固定成本可以被租用，而可租用的固定成本不产生规模经济——因为对手也能租。**

这一条会在未来几年推翻不少"规模就是护城河"的结论。判定时的具体动作是：**把 C 里面"必须自建"和"可以租用"的部分分开，只有前者进第一项。**
