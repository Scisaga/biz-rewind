# 第 12 章　AI 时代的七种力量重估

> **本章是原创补充。** 前面每章末尾都有一节重估，这里把它们放在一起看，因为**只有并排放着，才看得出方向性**。

---

## 一、一张总表

| 力量 | 方向 | 主要机制 |
| --- | --- | --- |
| **反向定位** | **↑↑ 强化，但寿命变短** | AI 让新模式的成本优势变得极大；同时也让在位者跟进的技术门槛消失 |
| **独占资源** | **↑↓ 剧烈分化** | 物理与法律约束的资源升值；"技术积累"型资源贬值 |
| **规模经济** | **↑↓ 两极分化** | 基础设施层固定成本暴增；应用层固定成本塌陷 |
| **网络经济** | **↓ 真伪加速分离** | 以"信息聚合"为价值的网络被绕开；以"人"和"真实供给"为价值的网络稳固 |
| **转换成本** | **↓↓ 削弱最严重** | 流程型转换成本（人重新学习的代价）被系统性消解 |
| **品牌** | **↓ 中间地带被挤压** | 情感效价稳固；不确定性削减型分化；靠曝光和记忆的一般品牌受损 |
| **流程效能** | **↓↓ 时间常数缩短** | 默会知识被观测与重现，"十年追不上"可能变成"三年追得上" |

**一眼可见的结论：**

> **两种稳定期力量（品牌、流程效能）同时受损，而它们恰恰是原书里最耐久的两种。**

这件事的含义比看起来严重。稳定期力量是成熟企业的**最后一层防线**——起飞期的窗口早已关闭，反向定位早已过期，剩下的就是品牌和流程。**如果这两种的时间常数都在缩短，那么成熟企业护城河的平均寿命在整体下降。**

---

## 二、贯穿七种力量的三条通用机制

上面七行不是七个独立的判断，它们背后是同三条机制在起作用。**掌握这三条，比记住七行结论更有用**——因为可以自己推导没被列出的情况。

### 机制一：可租用的东西不构成壁垒

**规模经济的第一项要求固定成本是"必须自建"的。** 一旦某种能力可以按需租用，它对所有玩家一视同仁，就不再产生规模差。

云计算已经在算力上做过一次，AI 正在把这件事扩展到更多能力上：过去要养一支大工程团队才能交付的东西，现在可以用小得多的固定投入交付。

**操作动作**：把 `C` 里"必须自建"和"可以租用"的部分分开，**只有前者进第一项**。

**这一条会推翻不少"规模就是护城河"的既有结论。**

### 机制二：讲不清楚的东西正在变得讲得清楚

**迟滞型壁垒（品牌、流程效能）的强度等于那个时间常数**，而时间常数的一半来自**不透明性**——讲不清、教不会、只能自己慢慢试。

AI 在系统性地侵蚀这一点：传感数据加模型可以把老师傅的手感反解成参数；流程可以被观测、记录、重现；优化过程可以被自动搜索，不必靠数十年试错。

**Helmer 引以为证的"即使丰田想教也教不会"，是这套壁垒的终极形态。而这句话正在变得不那么绝对。**

**操作动作**：对任何一条迟滞型力量，追加一问——**这里面有多少是可以被数据观测和模型重现的？** 那部分打折。

### 机制三：中介层正在被绕开

**信息中介的价值来自"到我这来能找到"。** 当答案可以被直接生成，这个动作本身就消失了。

受影响的不只是搜索和问答社区，还包括：以聚合信息为核心的平台、以比价和筛选为核心的中介、以整理和归纳为核心的服务，以及很大一部分以"帮你找到合适的东西"为价值主张的品牌。

**这一条对应第 11 章的"被绕开"，是当代最快也最容易被漏掉的崩塌模式。**

**操作动作**：对任何一门生意问——**它的价值是"帮人找到/理解信息"，还是"提供信息之外的东西"？** 前者要重估。

## 三、正在升值的东西

把三条机制反过来推，可以得到一张"什么在变得更值钱"的清单：

| 类别 | 为什么 |
| --- | --- |
| **必须自建的巨额固定成本** | 前沿训练、算力基础设施、配套电力、重资产制造。**租不到，所以仍产生规模差** |
| **物理世界的复杂协同** | 涉及真实物料、设备、人员的多方协同，其复杂性无法被观测数据完全捕捉 |
| **法律与行政裁定的排他权** | 专利、牌照、产区、矿权——"决"型壁垒不受能力普遍提升的影响 |
| **真实的人际网络** | 无法被生成或合成。**这是少数完全不受影响的力量** |
| **真实供给的双边市场** | 锁定的是现实世界的供给能力，不是信息 |
| **责任归属型的品牌** | 出了事谁负责，这不是信息问题，AI 解决不了 |
| **情感效价型的品牌** | AI 帮不了你炫耀 |

**一条概括：稀缺性来自物理约束、法律约束、和人的选择的，仍然稀缺；稀缺性只来自"别人还不会"的，正在失效。**

## 四、正在贬值的东西

| 类别 | 为什么 |
| --- | --- |
| **"我们技术积累深厚"** | 可被快速复现的能力在快速贬值 |
| **"我们数据量最大"** | 方法的一次跃迁可以一次性抹平数据量差距 |
| **流程型转换成本** | "人要重新学"的代价正在被消解，**且逐年加深折扣** |
| **应用层的团队规模优势** | 固定成本塌陷 |
| **靠曝光和货架建立的一般消费品牌** | 分发逻辑从"你记得哪个"变成"系统认为哪个合适" |
| **可被观测重现的运营诀窍** | 迟滞消失 |
| **以信息聚合为价值的网络** | 被绕开 |

**这张表的用法**：拿它去核对现有的护城河论述。**如果一家公司的护城河论证主要落在这张表里，它的估值假设需要重估。**

## 五、两个尚未定型、值得持续观察的问题

这两件事现在还看不清，但方向重要，所以记录下来而不下结论。

### 一、当客户不是人的时候，品牌是什么

如果越来越多的采购与选择由智能体代理执行，那么：
- **情感效价对机器无效**——机器不需要炫耀，也不会被联想打动
- **降低不确定性对机器仍然有效**，但形态会变——它需要的不是"我听说过这家"，而是**可验证的一致品质记录**

这可能意味着一种新型的品牌资产：**面向机器的、可查证的可靠性档案**。它是不是仍然符合原书"由历史信息带来的、对客观相同产品的更高价值归属"的定义？技术上符合——**历史信息、客观相同、愿意多付**，三个要件都在。只是承载它的不再是人的记忆。

**现在无法判定，但值得每年重看一次。**

### 二、大模型工程体系会不会成为新的流程效能

训练与部署大规模模型的工程实践，目前高度依赖默会知识——**复杂性和不透明性两个条件都满足**。

但它**不满足时间条件**。按第 9 章的门槛（≥5 年**且跨越一个完整下行周期**），它还没有经历过一次真正的行业下行——而那恰恰是唯一能把流程效能和顺周期运气分开的检验。

**处理方式：记录，不判定。** 这正是原书教给我们的纪律——**如果时间常数还没经受检验，就不能称之为迟滞型壁垒。** 现在把它叫做护城河，是在犯这本书专门警告过的错误。

## 六、一个方法论上的自我提醒

本章列的所有结论，都建立在"AI 能力将持续快速提升"这个前提上。这个前提本身是不确定的。

更重要的是，**这一章示范的动作比结论更有价值**：

> 拿七种力量的**壁垒机制**（不是力量名称）去对照任何一次技术或制度变迁，问：**这次变迁改变了四种壁垒机制中的哪一种？**

- 改变了"份额的价格" → 影响规模、网络、转换成本
- 改变了"在位者的自伤程度" → 影响反向定位
- 改变了"裁定" → 影响独占资源
- 改变了"时间常数" → 影响品牌、流程效能

**这个动作对下一次变迁同样有效**，无论那次变迁是什么。

这也是这本书真正耐用的地方：**七种力量是结论，四种壁垒机制才是引擎。** 结论会过期，引擎不会。
