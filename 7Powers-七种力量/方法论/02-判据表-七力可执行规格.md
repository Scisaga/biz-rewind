# 判据表：七种力量的可执行规格

> **本文件是整个项目最核心的资产。** 书稿引用它，未来的分析工具编译它。
> 所有阈值分两类标注：**【原书】** = Helmer 原文给出；**【拟定】** = 本项目的经验假设。
>
> **版本 v2（2026-09-10）** —— 已按 [04-判据回测与阈值校准](04-判据回测与阈值校准.md) 第一轮 20 个样本的结果修订。
> 主要变化：改用 SLM 单一阈值 · C 改为"必须自建" · 新增**功能性替代扫描** · 流程效能改用周期 · 反向定位改三档 · 外挂否决项扩为两条。

## 使用顺序（不可跳步）

```
① 业务切分       上市公司 → 战略独立的业务（分部），每个业务单独走一遍
② 阶段闸门       业务单位增速 → 原生/起飞/稳定 → 候选 Power 只剩 2–3 种
③ 功能性替代扫描 ★ 客户要完成的那件事，还走不走我们这条路径
④ 竞争者枚举     现有 + 潜在 + 功能性替代者，逐一列出
⑤ 逐力检验       候选 Power × 每个竞争者 → 先查壁垒，壁垒不成立立即出局
⑥ 3S 闸门        Superior / Significant / Sustainable，任一不过则降级为"经营优秀"
⑦ 价值映射       填 M0·g·s·m，指定主导力量，与市价反解的隐含 m 对比
⑧ 外挂否决项     上下游议价挤压 / 财务结构风险（可否决，不可新增）
⑨ 派生监控       每条成立的结论输出证伪触发器
```

**顺序依据（回测第一轮）**：② 以极低成本独立拦下 2/7 个伪力量样本；③ 是唯一能发现"被绕开"型崩塌的一步；⑤ 内部先跑网络经济 δ 与规模经济 C 口径，这两台筛子合计拦下 7 个负样本中的 5 个。

**第 ④ 步的铁律：先查壁垒（Barrier），不查好处（Benefit）。** 好处遍地都是，壁垒才稀缺。

## 总表

| Power | 壁垒机制 | 窗口期 | 核心判据 | 一票否决条件 |
| --- | --- | --- | --- | --- |
| 规模经济 | 抢份额成本 | 起飞 | `SLM = (自建固定成本/龙头收入) × (龙头/追随者收入 − 1)` | **SLM < 5%** 【拟定 v2】 |
| 网络经济 | 抢份额成本 | 起飞 | `SLM = 1 − 1/[1 + δ(N_S − N_W)]` | **SLM < 5%**，或**多宿主重合度极高** 【拟定 v2】 |
| 反向定位 | 附带损害 | 原生 | 五阶段定位 + δ **方向**（三档判定） | **在位者做出实质性承诺（非浅尝辄止）且未受损** |
| 转换成本 | 抢份额成本 | 起飞 | `Δ = 迁移总成本 / 客户年支出` | **不存在后续购买品类**（结构性不成立） |
| 品牌 | 迟滞 | 稳定 | 同规格价差倍数 B 及其跨周期稳定性 | 促销季价差消失 → 是营销不是品牌 |
| 独占资源 | 决/法定 | 原生 | 五项检验（特异／未套利／可转移／持续／充分） | **资源是高价竞拍/公允估值取得** → 超额收益已付出 |
| 流程效能 | 迟滞 | 稳定 | 相对偏离 ≥5 年**且跨越一个完整下行周期** | 未经历下行周期，或下行期优势收窄 【拟定 v2】 |

## 一、规模经济 Scale Economies

**成立要求**：单位成本随规模下降，且龙头与追随者之间存在**难以逾越的规模差**。

### 计算

```
SLM = [ C / R_leader ] × [ R_leader / R_follower − 1 ]
       └─ 规模经济强度 ─┘  └──── 规模优势 ────┘

C ≡ 必须自建的固定成本【v2 修订】
  = 全部固定成本 − 可对外租用/代工/外包的部分
```

**为什么要扣除可租用部分**：可租用的固定成本对所有玩家一视同仁，不产生规模差（见第 12 章机制一）。判定时必须显式列出扣除项。

\g<0>

### 判定阈值【拟定 v2】

**直接对 SLM 设阈值，不对两个因子分别设阈值**——两者是相乘关系，分别卡门槛会同时犯两类错误（`1.3x × 5% = 1.5%`，两项都"过"却毫无意义；`3.0x × 4% = 8%`，一项"不过"却是有意义的）。

| SLM | 判定 |
| --- | --- |
| < 5% | **不成立** |
| 5–10% | 弱／证据不足 |
| > 10% | 成立 |
| > 25% | 强 |

**前置快筛**：规模差 <1.3 倍 **且** 自建固定成本占收入 <5% 时，SLM 必然 <5%，可直接出局，不必细算。

**同一套阈值适用于网络经济的 SLM。**

### 先确定是哪一种规模经济（原书列了五种）

| 来源 | 取数重点 | 备注 |
| --- | --- | --- |
| 固定成本摊薄 | C / 收入 | 最常见，下表展开 |
| 体积／面积关系 | 单位产能造价随规模下降的斜率 | 储罐、仓库、船舶 |
| **配送网络密度** | **单位面积客户数**，非全国总量 | **地理边界问题的根源** |
| 学习经济 | 累计产量 vs 良率／单位成本 | 与流程效能易混：看优势是否随人员更替流失 |
| 采购经济 | 投入品采购单价差 | **五种里壁垒最弱**：计入但标注可持续性存疑 |

### 固定成本 C 的取数口径（分行业）

| 行业类型 | C 的近似 |
| --- | --- |
| 半导体/面板/化工 | 折旧摊销 + 研发费用 |
| 软件/SaaS | 研发费用 + 平台运维 |
| 内容平台 | 自制内容摊销 + 版权采购摊销 |
| 大模型 | 训练算力折旧 + 研究人员薪酬（**当代最纯粹的固定成本型规模经济**） |
| 连锁零售/餐饮 | 供应链与中央厨房折旧 + 总部费用（**注意门店成本是变动成本，不能计入**） |
| 医药 | 研发费用（临床开支） |

### 需要的数据

| 字段 | 来源 |
| --- | --- |
| 分部收入、折旧摊销、研发费用 | 财报（分部报告优先） |
| 主要竞争者的同口径收入 | 财报 / 行业数据 |
| 市场份额 | 行业协会、第三方数据 |

### 常见误判

- **把变动成本当固定成本**。门店、人力、原材料随规模线性增长的，不产生规模经济。
- **地理边界忽略**。规模经济常有地理边界（外卖、生鲜、水泥、区域连锁）——全国第一但在某省是第三，在那个省就没有 Power。
- **采购经济要单独标注。** 它是规模经济的合法来源（原书列出），但供应商集中或合同重谈时会被拿回去——**计入，但标注可持续性存疑，不得单独支撑结论**。

### 证伪与衰减信号

- 龙头/追随者收入倍数持续收窄
- 行业出现技术路线切换，使既有固定资产贬值（旧产能的规模优势归零）
- 龙头毛利率与追随者收敛

## 二、网络经济 Network Economies

**成立要求**：用户数增加使产品对**每个用户**的价值上升，且该增值**重大**。

### 计算

```
SLM = 1 − 1 / [ 1 + δ (N_S − N_W) ]

δ ≡ 每单位网络规模差带来的价值增量系数
N ≡ 网络规模（用户/商户/开发者/节点数）
```

`δ → 0` 时 SLM → 0。**这是最重要的一道闸门**：作者原话就是针对"很多公司鼓吹网络效应，仔细一看根本不重大"。

### δ 的实证替代变量（因为 δ 无法直接观测）

用**同期对手的定价/留存差**反推：

| 观察项 | 含义 |
| --- | --- |
| 同类服务的 ARPU 溢价 | 网络规模是否转化为定价权 |
| 留存率 / 月活跃留存差 | 网络规模是否转化为粘性 |
| 获客成本（CAC）差 | 网络是否自带获客 |
| 供给侧参与意愿差（商户/开发者数量增速） | 双边网络的另一侧是否被吸引 |

**第五个变量【v2 新增】：多宿主重合度。** 用户／商户同时使用几家？重合度高，δ 的实际效力就低——用户不需要"放弃"任何一方，网络效应就不产生转移成本。

**判定规则【v2】**：
```
五项（ARPU 溢价 / 留存差 / CAC 差 / 供给侧参与意愿差 / 多宿主）
中三项以上不利   →  不成立
多宿主重合度极高  →  单项即可否决
SLM < 5%          →  不成立
```
**回测依据**：多宿主单独拦下 7 个伪力量样本中的 3 个，此前却不在正式判据里。

### 三个必查的行业特征【原书】

1. **是否有临界点（赢家通吃）**：一旦某家取得领先，其余是否放弃。
2. **网络的边界在哪**：网络性质决定业务边界。要显式写出边界——地理的（网约车按城市成网）、人群的（职场 vs 熟人）、品类的。**边界之外没有 Power。**
3. **早期产品是否决定胜负**：起飞期谁扩张最快，往往由谁最早把产品做对决定。

### 常见误判

- **把规模经济当网络经济**。用户多导致成本摊薄 = 规模经济；用户多导致**产品对用户更有用** = 网络经济。二者壁垒强度不同。
- **把"数据飞轮"默认当网络经济**。必须回答：更多数据是否**显著**改善了每个用户感知到的产品质量，且这种改善**不能被对手用更少数据 + 更好方法追平**。多数情况下过不了 Significant 这一关。
- **多宿主（multi-homing）**。用户同时用三家，网络效应基本被抵消。必查用户重合度。

## 三、反向定位 Counter-Positioning

**成立要求**：新进入者采用更优的新商业模式，而在位者**经过理性计算后选择不跟**。

### 判定的三段式（缺一不可）

```
① 新模式确实更优         → 成本更低 和/或 可卖更高价（要能算出来）
② 在位者若跟进会自伤     → 自我蚕食率 δ 高，跟进的净利润变化为负
③ 在位者实际上没跟       → 且没跟的理由是"算过账"，不是"没看见"
```

\g<0>

### 在位者五阶段（可观测的壁垒读数）

```
否认 Denial → 嘲讽 Ridicule → 恐惧 Fear → 愤怒 Anger → 投降 Capitulation（常已太迟）
```

把管理层公开表态定位到某一级，级别即壁垒强度：**否认／嘲讽 = 最强；恐惧 = 仍强；愤怒 = 开始松动；投降 = 结束。**

### ★ "浅尝辄止（dabbling）"不算跟进

| 现象 | 判定 |
| --- | --- |
| 上线对标产品，但资源、定价权、渠道政策照旧 | **浅尝辄止 → 反向定位仍成立** |
| 独立主体 + 独立考核 + 核心资源倾斜 + 接受主业受损 | **实质跟进 → 不成立** |

### 联合观察清单（原书）

```
挑战者：份额快速上升 ／ 盈利能力强或有明确前景
在位者：份额流失 ／ 无力反制 ／ 管理层动荡 ／ 投降太迟
```
在位者四项同时出现 → 成立概率高。

### 结构特点

- **非排他**：同一在位者可同时被多个挑战者反向定位 → **赛道拥挤不构成反证**
- **竞争位置是二元的**：你有没有采用异端模式；强度全部来自模式的优越性与预期附带损害

### 需要的数据

| 字段 | 来源 |
| --- | --- |
| 在位者的收入结构（受威胁业务占比） | 在位者分部报告 |
| 在位者的渠道/人员固定成本结构 | 在位者财报、招股书 |
| 在位者管理层对新模式的公开表态 | 公告、业绩会纪要、访谈 |
| 在位者的资本开支方向 | 财报现金流量表、公告 |

### 三档判定【v2】

```
成立      在位者处于否认/嘲讽/恐惧阶段，且无实质资源投入
正在失效  在位者进入愤怒阶段；或已浅尝辄止但资源开始倾斜；δ 方向向下
不成立    在位者做出实质性承诺（独立主体 + 资源倾斜 + 接受主业受损）且未受实质损害
```

**并强制输出 δ 的方向（上升／持平／下降）与依据。** 这是唯一自带到期日的力量，不给方向等于没给结论。

一票否决的经典反例：微软全面转向云与订阅，主动接受对本地授权收入的自我蚕食——**这是实质性承诺，不是浅尝辄止**。

### 衰减机制【原书唯一给出的衰减模型】

自我蚕食率 δ 随时间**自然下降**（在位者的旧业务本来就在萎缩，跟进的边际损失越来越小）→ SLM 下降 → 附带损害减弱 → **反向定位是七种力量中最会过期的一种**。

因此该结论必须带**有效期**，且需定期重估 δ。

## 四、转换成本 Switching Costs

**成立要求**：客户对**后续购买**存在迁移损失。

### 三个结构性限定【原书】

1. **只对存量客户有效**——对争取新客户毫无帮助；
2. **必须存在后续购买品类**——没有续购，就没有 Benefit（结构性不成立，直接出局）；
3. 强者的定价上限 = 对手价格 + 转换成本 Δ。

### 计算

```
Δ / 客户年支出 = 转换成本强度
```

### 结构特点：非排他 + 竞争位置二元【原书】

> 转换成本是非排他性的力量：好处对所有玩家开放，**强度来自行业经济结构**；潜在好处只有在你拥有客户时才归属你，**因此竞争位置部分是二元的：你要么拥有这个客户，要么没有。**

判定含义：**不要比较"谁的转换成本更高"，而要算"这个行业的 Δ／年支出是多少"，再看各自锁住了多少存量。** 另：转换成本可外溢为网络经济或品牌，**但不得重复计入**。

**原书预警**：这类优势可能被技术剧变一扫而空（原文举的是云对 ERP，机制与今天 AI 对流程型转换成本相同）。

### 三类转换成本与各自的证据【原书分类】

| 类型 | 内容 | 可查证据 |
| --- | --- | --- |
| **财务型** | 需重新购买的软硬件、数据迁移费、违约金 | 合同条款、云厂商出口费率、公告中的采购金额 |
| **流程型** | 重新学习、流程重构、切换期的业务风险 | 实施周期、认证人数、行业调研 |
| **关系型** | 人际关系、社区归属、身份认同 | 社区规模、开发者活跃度、NPS |

**三类同时具备的，是最强形态。**

### 需要的数据

续约率/流失率、存量客户的加价幅度（同产品对新老客户的价差）、客单价随合作年限的变化、实施周期长度。

### 常见误判

- **把"懒得换"当转换成本**。若对手补贴一次即可覆盖迁移成本，则 Δ 太小，不构成 Power。要算得出数。
- **忽略了 AI 正在系统性降低流程型转换成本**（代码迁移、数据格式转换、操作学习）。这一条在当下必须重估：**很多曾经成立的转换成本正在快速贬值。**

## 五、品牌 Branding

**成立要求**：对**客观上相同**的产品，客户持久地愿意付更高的价，且原因来自卖方的历史信息。

### 计算

```
B = 强者售价 / 客观等同产品的售价     （品牌溢价倍数）
```

必须同时满足：
- **同规格可比**（否则测的是产品差异，不是品牌）
- **跨周期稳定**（【拟定】至少三年，含一个促销周期与一个需求下行期）

### 两条 Benefit 通路【原书】——需分别判断

| 通路 | 机制 | 适用品类 |
| --- | --- | --- |
| **情感效价** | 品牌联想带来的正面感受，独立于客观价值 | 奢侈品、白酒、时尚、汽车 |
| **降低不确定性** | 买了不会出错的"安心" | 医药、母婴、食品、B 端采购、工业件 |

### 需要的数据

同规格竞品的电商/渠道价格时序、毛利率与销售费用率的**联合**时序（**关键：真品牌是溢价高且销售费用率低；靠费用砸出来的溢价不算**）、促销季价差保持率。

### 一票否决【v2：分端】

```
C 端：促销季价差保持率降为零
B 端：竞争性招标中价差消失（B 端没有促销季，原判据不可用）
通用替补：需求下行期价差消失      ← 两端都适用，回测中最有效
```

### 其余衰减信号

- 促销季价差消失 → 是营销不是品牌
- **销售费用率上升而溢价不变** → 品牌在靠输血维持
- **品牌稀释**：向下延伸品类、过度授权、渠道失控（原书明确列出 D 稀释项）
- **跨品类迁移失败是常态**——爱马仕干邑、保时捷太阳镜；成功案例（迪士尼主题公园）罕见

### 阶段警告

品牌的壁垒是迟滞，**只可能在稳定期建立**。对高速成长期的公司谈品牌护城河，基本是错的。

## 六、独占资源 Cornered Resource

**成立要求**：以**有吸引力的条件**优先获取某种可独立提升价值的珍贵资产。

### 原书五项检验（必须全过，再加 3S 重大性）

```
① 特异性 Idiosyncratic     这事它能反复做到吗？能 → 真资源另有其物，重新隔离
② 未被套利 Non-arbitraged  ★ 取得价格是否吃掉了全部租金？
③ 可转移 Transferable      换一家公司，这项资源还创造价值吗？不能 → 你漏了互补条件
④ 持续性 Ongoing           把它拿走，超额回报会受损吗？已内化 → 不再是资源
⑤ 充分性 Sufficient        假定经营卓越，它单独足以支撑持续超额回报吗？
```

**建议顺序：先 ②（淘汰率最高、判断成本最低），再 ⑤④，最后 ①③。**

形式化：独占资源的 SLM 同时取决于资源带来的单位收益 **Δ** 与为其额外付出的年成本 **k**：

```
资源创造的价值 Δ  −  为它付出的代价 k  =  力量
```

| 检验 | 最常挂在这里的对象 |
| --- | --- |
| ① 特异性 | "我们连续拿到一批优质项目" → 真资源是那套获取能力，不是项目本身 |
| ② 未被套利 | 高价竞拍的矿权、公允估值的收购、市价挖来的团队 |
| ③ 可转移 | 只在本公司灵验的"资源"（说明存在未被识别的互补条件） |
| ④ 持续性 | 创始人／早期关键人物（价值已内化进组织） |
| ⑤ 充分性 | **"我们管理层优秀"**（柯达式误判） |

### 第 ② 问是最常被跳过、也最致命的一问

**高价竞拍来的矿权、按公允估值收购的专利、市价挖来的团队，都不构成 Power**——超额收益已经在获取价格里付给卖方了。

原书的时间逻辑也来自这里：**起飞之后资源价值被广泛知晓，就不可能再被低价获得**，所以独占资源的窗口只在原生期。

### 中国市场的常见形态与对应追问

| 形态 | 追问 |
| --- | --- |
| 牌照/特许经营 | 是行政授予还是高价拍得？年费与合规成本是否吞掉超额收益？ |
| 矿权/资源禀赋/产区 | 取得成本 vs 当前市场价；是否有排他的地理属性 |
| 专利/技术授权 | 剩余保护期？是否可绕开？诉讼记录如何 |
| 核心团队 | 有无股权绑定？留下的理由是财务的还是非财务的？（原书皮克斯案例的壁垒是"个人选择"） |
| 独家数据/独家内容 | 排他期多长？续约条款？对手能否用替代数据达到同等效果 |
| 上游产能配额 | 是长约锁定还是逐年谈判？ |

### 需要的数据

公告（牌照取得、专利受让、矿权竞拍价、股权激励与竞业协议）、专利数据库剩余期限、关键人员变动、长约条款披露。

### 证伪与衰减

- 资源到期时间表（专利悬崖、牌照续期、长约到期）——**这是可以提前若干年写进日历的**
- 关键人员离职
- 出现技术性绕开路径

## 七、流程效能 Process Power

**成立要求**：嵌入组织的流程带来持续的成本/质量优势，且**只能通过长期投入才能匹敌**。

### 时间尺度是这条的核心

原书举证：丰田花 **15 年**才把 TPS 传给自家供应商；NUMMI 表明**即使丰田想倾囊相授也做不到**。

**因此判据必须是长时序的：**

```
【拟定 v2】
≥ 5 年，且至少跨越一个完整的行业下行周期，
单位成本 / 良率 / 周转天数 相对同业的偏离持续存在且未收窄
```

**为什么改用周期而非纯年限**：年限只是代理变量，本质是"对手追不上"。**下行周期是对流程效能最强的检验**——订单减少时，流程优势表现为仍能保住良率、仍能盈利，而对手不能。这个判据更本质，且在周期性行业不必等满十年。

**未经历过完整下行周期的优势，一律先归为"经营优秀"。**

### 两个必查的壁垒来源【原书】

| 来源 | 检验方式 |
| --- | --- |
| **复杂性** | 改进是否牵动大量环节（供应链、产线、组织）？单点改进不构成 |
| **不透明性** | 是否为默会知识、未被正式编码？**若已被写成书、开源、或由咨询公司标准化输出 → 壁垒消失** |

### 需要的数据

毛利率/单位成本/存货周转/良率的**十年时序**（自身与同业）、人员流动率（流程效能应当**不随人员更替流失**，这是与"能人依赖"的分界）、产能爬坡速度。

### 常见误判

- **把一次性的成本领先当流程效能**。低价原料、低价土地、补贴，都不是。
- **把"能人"当流程**。原书明确：流程效能的特征是新人进来、老人退休，优势仍在。若优势随某人离职消失，那是独占资源（且脆弱），不是流程效能。
- **忽视 AI 对不透明性的侵蚀**。流程知识正在以前所未有的速度被观测、复制与再现，这一条的时间常数在缩短。

## 附：功能性替代扫描（★ v2 新增，每条力量结论必过）

**这是回测第一轮发现的唯一逻辑漏洞。** 判据表其余所有检验都是**在既有竞争框架内**比较——和同类对手比份额、比留存、比溢价——因而对"整条路径被绕开"完全盲视。回测中有两个案例在崩塌前逐项检查全部"成立"，且市场份额仍在上升。

```
Q1  客户真正要完成的那件事是什么？（不是"我们的产品是什么"）
Q2  完成这件事，现在有几条路径？
Q3  近 12 个月，走我们这条路径的人占比是上升还是下降？
Q4  若某条新路径的成本/体验按当前速度改善，多久跨过临界？

判定：Q3 下降 且 Q4 < 24 个月
      → 所有力量结论降级为"高风险"，无论其自身判据多么成立
```

**Q3 的口径是关键**：分母是"**完成这件事的所有人**"，不是"这个市场的用户"。**市场份额在这类崩塌里会上升**——你在一个正在消失的市场里份额还在涨，这正是它骗人的地方。

**数据需求与其余各步不同**：需要用户行为的替代关系，而非财务与份额数据。**应记入数据侧需求清单。**

## 附：外挂否决项（可否决，不可新增力量）

Helmer 主动把范围划窄以换取可判定性，代价是有些致命因素落在框架外。它们只能外挂。

| 否决项 | 内容 | 先行指标 |
| --- | --- | --- |
| **1. 上下游议价挤压** | 力量还在，但钱被产业链其他环节拿走（原书明确排除，归波特五力） | 收入增长与毛利率背离 |
| **2. 财务结构风险** | 期限错配、杠杆、现金流缺口 | 资产负债表先于利润表恶化 |

## 附：3S 闸门（每条结论必过）

| 检验 | 问题 | 不过的处理 |
| --- | --- | --- |
| **Superior** 优越 | 是否真的改善了自由现金流？ | 出局 |
| **Significant** 重大 | 改善幅度是否实质？能否折成 `m` 的几个百分点？ | **降级为"经营优秀"，不进战略结论** |
| **Sustainable** 可持续 | 竞争者（含潜在与功能性）能否套利掉？ | 出局 |

## 附：结论的输出结构

每条 Power 判定必须携带以下字段，否则不算完成：

```yaml
业务: <战略独立业务名，非公司名>
阶段: 原生 | 起飞 | 稳定       # 附计算依据（单位增速）
竞争者: <具体某一家>            # 含类型：现有/潜在/功能性
power类型: <七选一>
壁垒: 成立 | 不成立 | 证据不足   # 先判这个
好处: <具体机制>
指标: <名称与数值>
3S: {superior: , significant: , sustainable: }
证据: [<出处1>, <出处2>]
主导力量: 是 | 否            # 多力量叠加时只有一个主导；其余不重复计入 m
功能性替代: 通过 | 高风险
置信度: 高 | 中 | 低
证伪条件: [<看到什么就推翻>]
崩塌模式: 被追平|被绕开|被作废|被自毁|被上下游挤走|被反向定位   # 决定盯哪个先行指标
有效期: <到期需重估的时间>
```

**允许且鼓励输出"证据不足"**。这比编一个理由更有价值。
