# 分析管线架构（设计稿，暂缓实施）

> **状态：冻结中。** MCP 侧仍在开发，本文件只记录设计结论与待确认问题，不做实现。
> 依赖的判据来自 [02-判据表-七力可执行规格.md](02-判据表-七力可执行规格.md)。

## 一、一条必须先接受的边界条件

Helmer 在附录 8.1 自己承认：**7 Powers 在信息透明的公司上不产生 alpha。**

他的原始论证：绝大多数情况下 Power 的潜力与市场规模对专业投资者是显而易见的，常常已经写在历史财务数据里；alpha 依赖于对半强式有效市场假说的例外，也就是**实质性的信息优势**——而这种场合只出现在**不透明（opacity）**且**该不透明可被 7 Powers 穿透**的地方。不透明的首要来源是**高通量（high flux）**。

**推论（决定整个系统的形态）：**

> 不要做成"给全市场公司打护城河分"。那是把算力花在市场早已定价的地方，做出来好看，但没有信息价值。

正确形态是**两段式**：

```
第一段（廉价，全市场跑）：flux 筛子 → 找出正处在"价值时刻"的业务
第二段（昂贵，少量标的）：七力深度检验 → 只对第一段的输出做
```

### flux 筛子的候选信号

| 信号 | 数据源 |
| --- | --- |
| 业务级增速发生跳变（进入或退出 30–40% 区间） | 分部报告时序 |
| 业务结构突变（新分部出现、旧分部萎缩过半） | 分部报告、公告 |
| 在位者**首次公开回应**新进入者 | 业绩说明会、公告、访谈 |
| 关键资源的取得或到期（牌照、专利、长约） | 公告、专利库 |
| 产业链图谱上出现新节点或新边 | 产业链图谱 |
| 研报一致预期的**分歧度**放大（不是方向，是方差） | 研报 |
| 技术路线切换的公开证据 | 资讯、专利、招标 |

**最后一条尤其值钱**：一致预期的**分歧度**比一致预期的**水平**更能定位不透明区域。

## 二、分层架构

```
L0   公理层      价值公理 / 箴言 / Benefit+Barrier / 3S       稳定的小段提示词，几乎不变
L1   业务切分    上市公司 → 战略独立业务                      分部报告 + 公告 + 产业链图谱
L2   阶段闸门    业务级单位增速 → 原生/起飞/稳定               候选 Power 收敛到 ≤3
L2.5 替代扫描 ★  客户要完成的事，还走不走这条路径             用户行为替代数据（新需求）
L3   逐力检验    候选 Power × 每个竞争者 → 壁垒优先 → 指标     判据表编译成的检查流程
L4   竞争矩阵    含潜在 + 功能性替代者                         产业链图谱 + 资讯
L5   价值映射    填 M0·g·s·m，指定主导力量，对比隐含 m         行情 + 研报 + 财报
L5.5 外挂否决 ★  上下游议价挤压 / 财务结构风险                 产业链图谱 + 财报
L6   跟踪证伪    每条结论派生监控触发器                        定时任务轮询公告与数据
```

**L2.5 与 L5.5 是第一轮回测后新增的两层**（见 [04-判据回测与阈值校准](04-判据回测与阈值校准.md)）。L2.5 尤其关键：回测中有两个案例在崩塌前逐项检查全部"成立"、市场份额甚至仍在上升，判据表毫无预警——因为其余所有检验都是在**既有竞争框架内**做比较。

### 各层的关键设计点

**L1 业务切分**是整条链最容易被跳过、也最能拉开差距的一步。原书的"单一业务原则"要求分析对象是**战略独立的业务**，而不是法人公司。英特尔的存储与微处理器是两个正交的战略问题——同一套管理层、同一套工艺、同样的经营卓越，结局是 0 与 1500 亿。

对 A 股大量多元化公司，这一步直接决定结论是否有意义。**输出应当是：公司 → N 个业务，每个业务附带自己的市场定义、竞争者集合、增长阶段。**

**L2 阶段闸门**是搜索剪枝。原书给的分界是**业务单位增速 30–40%/年**。注意三点：
- 是**业务**增速，不是行业增速（业务增速才反映该公司面临的通量）
- 是**单位**增速优先于金额增速（避免涨价扰动）
- **不等同于产品生命周期**：原生期可能长期无销售，稳定期覆盖生命周期的成长中后段到衰退

**L3 逐力检验**必须内建"先壁垒后好处"的顺序，且允许并鼓励输出"证据不足"。

**L4 竞争矩阵**：输出是矩阵而非评分。一个"护城河 8 分"是无意义的；"对 A：规模经济成立，SLM≈12%；对潜在进入者 B：无；对功能性替代 C：证据不足"才是可决策的。

**L5 价值映射**是唯一与价格发生关系的一层。做法：
```
自下而上填  M0 · g · s · m   → 得到基本面价值区间
自上而下反解 当前市值隐含的 m  → 得到市场共识
两者之差 = 分歧点，且必须能说清分歧来自哪个槽位
```
**只有能说清分歧在哪个槽位的结论，才值得下注。**

**L6 跟踪证伪**：把静态判断变成可持仓跟踪的东西。每条成立的结论在 L3 已经产出了 `证伪条件` 与 `有效期` 字段，这层负责把它们变成定时检查。

## 三、输出必须是结构化且可版本比对的

报告是渲染出来的副产品，**真源是结构化记录**。原因只有一个：

> 只有可 diff，"上季判定规模经济成立、本季 SLM 从 12% 降到 7%、触发降级"才可能自动发生。

而这恰恰是原书最大的缺口所在——见 [01-重构思路-讨论纪要.md](01-重构思路-讨论纪要.md) 第四节"Power 的衰减检测"。

字段结构见判据表末尾的输出规格。

## 四、暂缓，但需要先想清楚的问题

### 待确认（依赖 MCP 侧的进展）

1. **能否拿到分部级数据？** 不是公司级的收入/成本时序，而是**分部级**的。L1 与 L2 的可行性完全取决于这一条。若拿不到分部数据，退路是用公告 + 研报做半自动切分，成本高很多。
2. **产业链图谱是否包含"竞争关系"边？** 若只有上下游供需边，L4 的潜在竞争者与功能性替代者就得另想办法（可从研报的可比公司集合、招标同场竞争记录中抽取）。
3. **行业份额数据的来源与可比口径。** SLM 的第二项直接依赖它。
4. **研报的结构化程度**：能否抽出一致预期数值序列（用于算分歧度）、可比公司集合、以及关键假设。
5. **★ 用户行为替代数据（L2.5 的新需求）**：能否观察到"完成同一件事的人当中，走某条路径的占比变化"？**这与其余各层的需求完全不同——它不是财务或份额数据。** 没有它，功能性替代扫描就只是一个提醒，而不是一道检验。可退而求其次的代理：搜索与流量趋势、招聘岗位结构变化、行业调研中替代方案的提及率、公告与业绩会中客户流失原因的表述变化。
