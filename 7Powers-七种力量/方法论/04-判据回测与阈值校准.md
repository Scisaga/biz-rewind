# 判据回测与阈值校准（第一轮）

> **目的**：不是验证 7 Powers 框架对不对（原书已用 400+ 案例做过），而是校准**我们自己填进判据表的那些数字和顺序**——1.3 倍规模差、5% 固定成本占比、8–10 年流程效能门槛，这些都是本项目的假设。
>
> **日期**：2026-09-10　**样本**：20 个已知结局的业务

---

## 〇、先声明这次回测的性质与边界

**这是一次纸面回测（desk backtest），不是数据回测。**

- 用的是公开常识级的定性事实与方向性判断，**不是从财务数据算出来的 SLM**
- 因此**不引用具体财务数字**——凡涉及数量级的地方都标注为判断，不是测量
- 部分案例的归因存在合理争议，本文采用最主流的解释，并在有分歧处标出

**它能校准什么：**
- 判据的**结构**（该问哪些问题、有没有漏问）
- 判据的**顺序**（哪一道筛子淘汰率最高，应该排在前面）
- 阈值的**方向**（现在的数是偏松还是偏紧）
- 规格的**结构性缺口**（有没有一类失败是判据表事前完全看不见的）

**它不能校准什么：**
- 精确的数值阈值。那必须等接上真实数据后重跑。

**尽管如此，本轮回测产出了 3 处结构性修改和 5 处阈值修订**，其中一处（功能性替代扫描的缺失）是判据表的真实漏洞——不是数字调整，是逻辑上少了一步。

## 三、值得展开的六个案例

### 案例 1+2：Intel 双业务对照（判据表的单元测试）

**为什么先跑这个**：同一家公司、同一批人、同样的经营卓越，结局 0 与上千亿。如果判据表连这个都分不开，那它没有任何价值。

| | 存储器 | 微处理器 |
| --- | --- | --- |
| 阶段判定 | 起飞 | 起飞 |
| 候选力量 | 规模／网络／转换成本 | 规模／网络／转换成本 |
| **壁垒检查（先做）** | 抢份额成本：**日厂可以用资本+良率直接买到份额** → 不成立 | 抢份额成本：x86 指令集的软件生态与开发者投入 → 成立 |
| 好处 | 有（工艺领先、成本下降） | 有 |
| 判定 | **好处显著，壁垒为零 → 经营优秀，非力量** | 三项力量成立 |

**这一跑确认了两件事：**
1. 判据表能复现原书的核心对照，说明结构无误。
2. **"先看壁垒"这条顺序是有效的**——如果先列好处，两边看起来一模一样，根本分不开。

### 案例 5：先进制程代工 —— 暴露"重复计数"问题

判据表让三种力量各自成立：规模经济（先进产线与研发的巨额固定成本 + 显著规模差）、流程效能（良率的长期偏离）、独占资源（关键设备的优先获取）。

**问题**：如果各自算 SLM 再加总，`m` 会被严重高估。三者在现实中不是相加的——它们在很大程度上**解释同一笔超额利润**。

**规格修订（见 F7）**：输出时必须指定**主导力量**，其余标注"叠加，不重复计入 `m`"。

### 案例 13：共享办公 —— 判据表拦对了，但理由不完整

判据表判它不成立，理由是：租金随点位线性增长（不是固定成本），"社区网络效应" δ≈0（隔壁公司是谁对我的价值接近于零）。这两条都对。

**但它真正的致命伤不在七力范围内**：长租短租的期限错配，在需求收缩时直接击穿。这是资产负债表结构风险，**七种力量完全不覆盖**。

**这与"被上下游挤走"是同一类问题**：Helmer 刻意把范围划窄换取可判定性，代价是有些致命因素在框架外。**处理方式是外挂否决项，不是硬塞进七力。**

### 案例 15：独立视频会议 —— "捆绑"在规格里没有位置

产品明显更好，用户明显更满意。判据表判不成立的理由是：Δ 小（切换只是换个链接）、多宿主率极高（每个人电脑上装着三个）。**结论对。**

但它被套利的**具体方式**是捆绑——竞争者把等效功能塞进一个企业已经在买的套件里，边际价格接近零。

**这在判据表里没有对应项。** 它属于"功能性竞争者"，但功能性竞争者这一格目前只是一个提醒，没有具体检查动作。**见 F5 的修订。**

### 案例 18+19：在线作业辅导 与 技术问答社区 —— 本轮最重要的失败

**崩塌前，用判据表逐项检查，两者全部"成立"**：

| 检查项 | 崩塌前的答案 |
| --- | --- |
| 阶段 | 稳定 |
| 网络经济 δ 四变量 | 显著（用户越多，答案越全，对每个人越有用） |
| 临界点 | 有，历史上未易主 |
| 多宿主 | 低 |
| 品牌 | 有 |
| 相对指标 | 未收窄 |
| 市场份额 | **仍在上升** |

**判据表在崩塌前一刻给出的是"力量稳固"。**

**问题出在哪：** 判据表的每一项都是**在既有竞争框架内**比较——和同类对手比份额、比留存、比溢价。而这两个案例的死因是**整条路径被绕开**：用户不再需要"到一个有很多人的地方去找答案"这个动作本身。

**份额数据在这种崩塌里会骗人**：你在一个正在消失的市场里，份额还在上升。

**这不是阈值问题，是判据表缺了一步。** 见 F5——这是本轮唯一一处**逻辑修订**，其余都是数字调整。

### 案例 20：综合半导体龙头 —— 验证了先行指标的排序

崩塌过程中，各类指标出现的先后顺序，与第 11 章的排序一致：

```
制程节点时间表推迟（经营动作）              ← 最早
大客户开始分散订单（合同/客户行为）
相对良率与制程代差（相对指标）
单位成本优势收窄（单位经济性）
新设计导入率下降（增长结构）
利润率下滑                                  ← 最晚
```

**在利润率开始下滑之前，前四类信号已经出现了数年。**

**这条时序在本轮里只有一个样本支持，需要更多样本验证**，但它与理论推导一致，暂按可信处理。

## 四、负样本的失败模式统计

7 个伪力量样本，各自被哪一道筛子拦下：

| 拦截它的检验 | 命中数 | 备注 |
| --- | --- | --- |
| **网络经济 δ 四变量检验** | 4 | **主力筛子** |
| **规模经济的 C 口径**（变动成本被当成固定成本） | 3 | **第二主力** |
| **多宿主重合度** | 3 | 但它目前只是"必查项"，不是正式判据 |
| **阶段闸门**（稳定期力量被声称于起飞期业务） | 2 | **独立生效，成本极低** |
| 品牌的价差否决（下行期消失） | 1 | |
| 转换成本第 ③ 条（无后续购买） | 1 | |

**由此得出两个结论：**

**一、伪力量最常见的两种伪装是"网络效应"和"规模效应"**——恰恰因为这两个词最好用、最难被追问。而它们也恰恰是判据表里**唯二有可算公式**的两种，所以拦截率最高。**这是公式的价值所在，也再次说明砍掉数学是错的。**

**二、阶段闸门以极低成本独立拦下了 2 个样本。** 它是整张表里性价比最高的一步，应当**永远第一个执行**。

## 五、校准结论

### F1 ★ 用 SLM 单一阈值取代"两个因子分别设阈值"

**问题**：现行规格对规模经济设了两个独立门槛（规模差 ≥1.3 倍、固定成本占比 ≥5%）。回测发现这个设计本身有缺陷——两个因子是**相乘**关系，分别卡阈值会同时犯两类错误。

```
1.3 倍 × 5%  →  SLM = 1.5%    ← 两个门槛都"过"了，但结果毫无意义
3.0 倍 × 4%  →  SLM = 8%      ← 固定成本占比"不过"，但结果是有意义的
```

**修订：直接对 SLM 设阈值。**

| SLM | 判定 |
| --- | --- |
| < 5% | **不成立** |
| 5–10% | 弱／证据不足 |
| > 10% | 成立 |
| > 25% | 强 |

原来那对阈值降格为**快速排除的前置筛**（规模差 <1.3 倍且固定成本占比 <5% 时，SLM 必然 <5%，可直接出局，不必细算）。

**这一条同时适用于网络经济的 SLM。**

### F2 C 的口径改为"必须自建的固定成本"

回测中 3 个负样本栽在把变动成本当固定成本上（单车折旧、地推人力、点位租金）。而第 12 章的机制一又指出：可租用的固定成本不产生规模差。

**修订**：
```
C = 必须自建的固定成本
  = 全部固定成本 − 可对外租用/代工/外包的部分
```
判定时要显式列出扣除项。

### F3 流程效能：用"周期"替代"年限"

**问题**：8–10 年的门槛在制造业成立，但它是一个**代理变量**，而不是本质。本质是"对手追不上"。

**回测观察**：真正的流程效能样本有一个共同特征——**它们的相对优势跨越了完整的行业下行周期**。下行期是对流程效能最强的检验：订单减少时，流程优势表现为仍能保住良率、仍能盈利，而对手不能。

**修订**：
```
旧：连续 8–10 年，相对同业的偏离未收窄
新：≥5 年，且 至少跨越一个完整的行业下行周期，相对偏离未收窄
```

这个判据更本质，且在周期性行业更可操作（不必等满十年）。

### F4 网络经济：多宿主升为第五个正式变量

**问题**：多宿主拦下了 3 个样本，但它目前只是"必查项"，不是判据的一部分——判定规则只看四个变量。

**修订**：
```
旧：ARPU 溢价 / 留存差 / CAC 差 / 供给侧参与意愿差，三项以上无差异 → 不成立
新：上述四项 + 多宿主重合度，五项中三项以上不利 → 不成立
    且：多宿主重合度极高时，单项即可否决
```

**多宿主单项否决的理由**：如果用户不需要"放弃"任何一方，网络效应就不产生转移成本，δ 再大也换不来定价权。

### F5 ★★ 新增跨力量前置检查：功能性替代扫描

**这是本轮唯一的逻辑修订，也是最重要的一条。**

**问题**：案例 18、19 在崩塌前逐项检查全部成立。判据表的所有检验都是**在既有竞争框架内**做比较，因而对"整条路径被绕开"完全盲视。

**修订**：在阶段闸门之后、逐力检验之前，增加一步强制检查：

```
功能性替代扫描（每条力量结论都必须过）

Q1  客户真正要完成的那件事是什么？（不是"我们的产品是什么"）
Q2  完成这件事，现在有几条路径？
Q3  近 12 个月里，走我们这条路径的人占比是上升还是下降？
Q4  如果某条新路径的成本/体验以现在的速度改善，多久会跨过临界？

判定：Q3 下降 且 Q4 < 24 个月  →  所有力量结论降级为"高风险"，
                                  无论其自身判据多么成立
```

**关键在 Q3 的口径**：分母是"完成这件事的所有人"，**不是"这个市场的用户"**。市场份额在这类崩塌里会上升——这正是它骗人的地方。

**这一步的数据需求与其余各步不同**：它需要的是用户行为的替代关系，而不是财务与份额数据。这对数据侧是一个新要求，应当记入 MCP 的需求清单。

### F6 反向定位：二档改三档，并强制输出 δ 方向

**问题**：回测里有三种不同状态被压进了同一个"成立/不成立"：
- 在位者仍在"否认/嘲讽"（壁垒最强）
- 在位者"浅尝辄止"（壁垒仍在，但已在松动）
- 在位者做出实质性承诺（壁垒消失）

**修订**：
```
成立      在位者处于否认/嘲讽/恐惧，且无实质资源投入
正在失效  在位者进入愤怒阶段，或已浅尝辄止但资源开始倾斜；δ 方向向下
不成立    在位者做出实质性承诺（独立主体+资源倾斜+接受主业受损），且未受实质损害
```
并**强制输出 δ 的方向（上升/持平/下降）与依据**。这是唯一自带到期日的力量，不给方向就等于没给结论。

### F7 多力量叠加时禁止重复计数

**修订**：输出必须指定**主导力量**（对 `m` 贡献最大的那一个），其余标注"叠加，不重复计入 `m`"。价值映射时 `m` 取主导力量的估计，不做加总。

### F8 品牌的一票否决在 B 端需要替换

**问题**："促销季价差消失"在 B 端不可用（没有促销季）。

**修订**：
```
C 端：促销季价差保持率
B 端：竞争性招标中的价差保持率 + 被写进采购技术规范的频率
通用替补（两端都适用）：需求下行期的价差保持率   ← 回测中对案例 14 有效
```

### F9 外挂否决项从一条扩为两条

原规格已有"上下游议价"作为外挂。回测（案例 13）表明还需要第二条：

```
外挂否决项 1：上下游议价挤压（Helmer 主动排除）
外挂否决项 2：财务结构风险（期限错配、杠杆、现金流缺口）
```
**两者都能否决，都不能新增力量。**

### F10 执行顺序按淘汰率重排

回测统计出的实际淘汰率，与现行执行顺序不完全一致。

```
修订后的顺序：
① 业务切分
② 阶段闸门              ← 独立拦下 2/7，成本极低
③ 功能性替代扫描（新增）  ← 唯一能发现"被绕开"的一步
④ 竞争者枚举
⑤ 逐力检验（先壁垒）
   其中先跑网络经济 δ 与规模经济 C 口径——两台主力筛子
⑥ 3S 闸门
⑦ 价值映射（含主导力量指定）
⑧ 外挂否决项 ×2
⑨ 派生监控
```

---

## 六、修订后的阈值一览

| 项目 | 旧【拟定 v1】 | 新【拟定 v2】 | 依据 |
| --- | --- | --- | --- |
| 规模经济 | 规模差 ≥1.3x 且 C/R ≥5% | **SLM ≥10% 成立，<5% 不成立**；旧阈值降为前置快筛 | F1 |
| C 的口径 | 固定成本 | **必须自建的固定成本** | F2 |
| 流程效能 | 连续 8–10 年 | **≥5 年 且 跨越一个完整下行周期** | F3 |
| 网络经济 | 四变量，三项无差异即否 | **五变量（+多宿主）；多宿主极高可单项否决** | F4 |
| 反向定位 | 成立／不成立 | **成立／正在失效／不成立** + δ 方向 | F6 |
| 品牌否决 | 促销季价差消失 | **C 端促销季／B 端招标／通用：下行期价差** | F8 |

**这些仍然是【拟定】。** 本轮把它们从"凭感觉设的数"变成了"经过 20 个案例检查方向无误的数"，但**精确取值仍需数据回测**。

## 七、本轮暴露的、无法靠调参解决的三件事

**一、判据表看不见"被绕开"。** 已用 F5 补上一步，但那一步的**数据需求与其余各步完全不同**（需要用户行为替代关系，而不是财务与份额）。这条如果没有数据支撑，就只是一个提醒。

**二、七种力量不覆盖财务结构风险。** 这是 Helmer 主动划范围的代价，只能外挂。

**三、"捆绑"作为一种套利方式，在框架里没有位置。** 它既不是新进入者，也不是替代品，而是**一个已经在客户预算里的竞争者，把等效功能的边际价格降到接近零**。目前归入功能性竞争者处理，但值得后续单独研究——**在 AI 时代它会变得更常见，因为把一个能力塞进已有产品的成本正在急剧下降。**

## 八、下一批样本（第二轮建议）

本轮样本有两个明显偏差，下一轮应当纠正：

**偏差一：负样本集中在消费互联网。** 制造业、B 端软件、医药、周期品的伪力量样本几乎没有。这几类的失败模式很可能不同。

**偏差二：没有"判据表判不成立、但实际成立"的样本（假阴性）。** 本轮 6 个正例全部通过，说明没有误杀——但也可能是样本选得太典型。**下一轮应当刻意找那些"当时看起来不像有力量、后来证明有"的案例**，这类样本能检验判据表是不是过严。

候选方向：
- 早期不被看好但后来建立起力量的业务（检验假阴性）
- 制造业与 B 端的伪力量（补偏差一）
- 同一行业内成败分化的配对样本（控制变量最干净，如 Intel 双业务那种）
- 中国市场的反向定位样本（本轮只有一个，而这是对中国最有解释力的一种力量）

**每一轮回测都应当更新本文件，并同步修订 [02-判据表](02-判据表-七力可执行规格.md)。**
