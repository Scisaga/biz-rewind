# 第 8 章　科特《领导变革》

> **第二篇　管理与领导力**

## 原著小档案

| 项目 | 内容 |
| --- | --- |
| 书名 | 《领导变革》（*Leading Change*） |
| 作者 | 约翰·科特（John P. Kotter，1947— ） |
| 首版 | 1996 年（脱胎于 1995 年《哈佛商业评论》文章《变革为何失败》） |
| 作者身份 | 哈佛商学院教授，33 岁获终身教职，是当时哈佛商学院最年轻的终身教授之一 |

| 核心命题 | 组织变革的失败有固定的八种模式，因此也有固定的八个步骤；跳过任何一步都会付出代价 |

## 开场：为什么变革这么难

先处理一个数字。

几乎所有讨论变革管理的文章都会引用一句话："**70% 的组织变革以失败告终。**"这个数字通常被归到科特头上。

**必须说清楚：这个数字缺乏严格的实证基础。**科特在书中的原始表述要谨慎得多——他说的是，在他观察的公司中，只有少数变革取得了很好的成效，多数处在两端之间，**而失败往往集中在最初的几个阶段**。学者对"70%"这一数字的溯源研究发现，它并没有可靠的原始数据来源，更像是在反复引用中固化下来的都市传说。

**但这不影响这本书的价值。**科特真正的贡献不是那个统计数字，而是一个更有用的判断：**变革的失败不是随机的，它有可辨识、可重复的模式。**如果失败有模式，那么预防就有方法。

这个判断本身就是这本书方法论的核心，也是它区别于一般管理鸡汤的地方。

科特写这本书时的背景，是 1980—90 年代美国企业的大规模重组浪潮：流程再造、全面质量管理、并购整合、裁员瘦身、企业转型。他观察到一个反复出现的现象：**这些项目的技术方案往往是对的，失败发生在别的地方。**

他的结论是：**这些是"领导"问题，不是"管理"问题。**（这直接呼应了第 7 章本尼斯的区分。）管理擅长在既定系统内把事情做对——计划、预算、组织、控制；而变革要求的是改变系统本身——设定方向、动员人、激励人。**用管理的方法去做变革，是变革失败最普遍的原因。**

## 组织变革的八大错误

科特先讲错误，再讲步骤。这个顺序是有意的——**因为八个步骤就是八个错误的反面。**

### 错误一：容忍过度的自满

**这是科特认为最致命、也最普遍的错误。**

自满的表现不是懒惰。恰恰相反，自满的组织常常非常忙碌——开会、写报告、执行计划。**但所有的忙碌都发生在旧框架内部。**

科特列出了滋生自满的九个来源，其中最值得警惕的几条是：

- **没有明显可见的危机**（财务报表还看得过去）；
- **过多的表面资源**（宽敞的总部、充足的预算，暗示一切正常）；
- **绩效指标标准太低**（只跟自己去年比，不跟行业最优比）；
- **组织结构使人只关注局部指标**（每个部门的 KPI 都是绿的，公司却在下滑）；
- **反馈渠道以内部为主**（听不到外部真实的声音）；
- **管理层的"快乐言谈"**（happy talk）——高层反复强调成绩，无意中传递了"一切尽在掌握"的信号。

**科特给的判断标准很具体：只有当组织中约 75% 的管理层真心相信"照现在这样下去是不可接受的"，变革才有可能启动。**低于这个比例，后面七步都会在半路失去动力。

### 错误二：未能建立足够强大的领导联盟

**变革不可能由一个人完成，哪怕这个人是 CEO。**科特的观察是：即使是极有魅力的领导者，单打独斗推动的变革也几乎总是在他离开后回退。

常见的失败形态是：变革被交给一个"项目组"或某位副总，而这个团队缺乏足够的职位权力或公信力。**当变革的推动者不是组织中最有分量的一群人时，所有人都会明白这件事其实没那么重要。**

### 错误三：低估愿景的力量

**如果没有一个能在五分钟内讲清、并且让人产生兴趣和认同的方向陈述，变革就会退化成一堆互不相干的项目清单。**

科特的检验标准很实用：**如果你无法在五分钟内向一位同事说清变革要去哪里、为什么值得，并让他表现出理解和兴趣，那么这一步就没有完成。**

### 错误四：把愿景的沟通量少传播了十倍

这是科特最著名的一个论断，也是最有实操价值的一条。

他的原话大意是：**大多数公司在沟通变革愿景上的投入，比实际需要的少了 10 倍，甚至 100 倍、1000 倍。**

具体表现：一次全员大会 + 一封邮件 + 一份文件，然后管理层就认为"已经沟通过了"。而这些内容加起来，可能占员工在同一时期接收到的公司信息总量的 **0.58%**（科特在书中给出过一个类似的估算）。**其余 99% 都是日常运营信息，而它们仍然在按旧规则运转。**

### 错误五：允许障碍阻挡新愿景

员工理解了、也认同了愿景，然后回到岗位上发现：**旧的考核制度、旧的审批流程、旧的信息系统、旧的岗位职责，全都在惩罚新行为。**

科特特别指出**最难处理的一类障碍是人**——某位有实权的管理者不认同变革，公开配合、私下阻挠。**而组织对这类情况的处理速度，是所有人判断"这次是不是来真的"的核心依据。**

### 错误六：未能创造短期胜利

**变革如果在 12 到 24 个月内拿不出任何可见的成果，多数人会失去信念，怀疑者会重新占上风。**

### 错误七：过早宣布胜利

科特认为这是**最令人扼腕**的一个错误：变革取得了初步成效，管理层召开庆功会，宣布转型成功。而**变革的根基远未扎稳。**一旦紧迫感解除，旧的行为模式会以惊人的速度回流。

他的原话很形象：**新做法在文化中扎根需要三到十年；而宣布胜利只需要一场发布会。**

### 错误八：忽视把变革固化到文化中

变革若没有沉淀为"我们这里就是这么做事的"，那么当推动者离开、当外部压力减弱时，一切都会退回原点。

**这八个错误的后果是可以列举的：**新战略无法落地、并购拿不到预期协同、流程再造耗时超支、裁员没有真正降低成本、质量项目没有带来质量。**技术方案通常都是对的，输的是执行的社会过程。**

## 领导变革第一步：树立紧迫感

科特把这一步称为"**所有步骤中最重要、也最常被跳过的一步**"。

跳过它的原因很直接：**它令人不适。**建立紧迫感意味着要公开承认现状有严重问题，而这既伤害士气、又让在任管理者难堪、还可能吓到投资者和客户。**于是大多数组织选择了"温和启动"，然后在第三个月发现推不动了。**

### 三种状态的区分

科特后来在《紧迫感》一书中做了一个极重要的区分，很多读者不知道：

| 状态 | 特征 | 结果 |
| --- | --- | --- |
| **自满（complacency）** | "我们做得挺好，不用大改" | 完全无法启动变革 |
| **虚假紧迫感（false urgency）** | 大量的活动、加班、会议、焦虑，但都是**被动的、防御性的、内向的**忙碌 | **比自满更危险**——因为它看起来像紧迫感 |
| **真实紧迫感（true urgency）** | 一种**决心**：相信有巨大的机会与威胁，因此**今天就要有所行动**，并且行动是对外的、聚焦的 | 变革的唯一有效起点 |

**虚假紧迫感是这个框架里最有价值的洞察。**很多组织的高层看到大家在疯狂加班、会议排满，误以为紧迫感已经建立。**实际上焦虑不等于紧迫感。**焦虑产生的是防御——保护自己的地盘、避免被追责、多做汇报少做决定。真正的紧迫感产生的是**主动的、朝向外部的行动**。

### 怎么建立真实的紧迫感

科特给的方法都指向同一件事：**让人们亲眼看见外部的现实，而不是听转述。**

- **拿掉粉饰，公开真实数据**——市场份额的真实趋势、与最优竞争对手的差距、客户流失的原因；
- **让人直接接触客户和不满意的客户**。一份满意度报告的冲击力，远小于让工程师坐在客服身后听半天电话；
- **停止"快乐言谈"**。高层反复强调成绩，是自满最有效的培养基；
- **设定不可能用现有方法达成的目标**，从而迫使人承认"照老办法做不到"；
- **必要时，允许危机被看见**。科特有一个不太受欢迎但很现实的建议：有时候，**制造或允许一次可控的危机，是打破自满的唯一办法**。

一个经典手法值得记录：某公司高管把三十多个不同部门采购的、功能相同却互不兼容的手套摆满了会议桌，每副标上采购价——最贵和最便宜差了五倍多。**没有一份报告能比这张桌子更有说服力。**这就是把抽象的低效变成可见的现实。

## 领导变革第二步：组建领导团队

科特的观点非常明确：**变革必须由一个团队来领导，而这个团队必须足够强。**

他给出的"足够强"有四个维度，缺一不可：

| 要素 | 含义 | 缺失的后果 |
| --- | --- | --- |
| **职位权力** | 关键岗位的人要在里面，尤其是那些能否决变革的人 | 变革在关键节点被卡死 |
| **专业能力** | 覆盖相关的业务、技术、市场专长 | 决策脱离实际，方案不可行 |
| **公信力** | 团队成员在组织中被尊重，说话有人听 | 变革被视为"某些人的政治动作" |
| **领导力** | 有足够的驱动变革的能力，而不只是管理能力 | 变革退化为一个项目管理计划 |

除此之外还有两个条件：**团队内部的信任**，以及**共同的目标**。科特建议用共同的非正式活动（异地会议、共同经历的挑战）来建立信任——**因为跨部门的高管之间通常并不真的信任彼此，而变革恰恰需要他们放弃各自的地盘。**

**科特特别警告了两类人不能进入领导联盟：**

- **"大自我"（big egos）**——占据大量空间、无法与他人协作的人；
- **"毒蛇"（snakes）**——破坏信任、传播小道消息、在背后拆台的人。

即使他们能力很强、职位很高。**因为领导联盟的第一产品是信任的示范，一个破坏信任的人会让整个团队失效。**

## 领导变革第三步：设计愿景战略

科特对愿景的定义很务实：**愿景是对未来的一幅图景，它包含着为什么人们应当努力去创造这个未来的隐含或明确的理由。**

它有三个功能：

1. **澄清方向**——让成百上千个决策不必逐一请示；
2. **激励行动**——包括那些短期内对个人不利的行动；
3. **协调行动**——让不同部门在不需要大量沟通的情况下保持一致。

### 有效愿景的六个特征

科特给了一份检查表，非常实用：

| 特征 | 含义 |
| --- | --- |
| **可想象（Imaginable）** | 能让人在脑子里形成一幅具体图景，而不是一堆抽象名词 |
| **可期望（Desirable）** | 长期来看，对员工、客户、股东都有吸引力 |
| **可行（Feasible）** | 是有挑战但现实可达的目标，不是幻想 |
| **聚焦（Focused）** | 足够清晰，能为决策提供指引 |
| **灵活（Flexible）** | 留出根据条件变化调整具体路径的空间 |
| **可沟通（Communicable）** | **五分钟内能讲清，并让对方产生理解与兴趣** |

**最后一条是最好的自检工具。**科特的说法是：如果你需要三十分钟和一套幻灯片才能解释你的愿景，那它还不是愿景，它是一份规划文件。

### 愿景不是什么

- **不是财务目标。**"三年内收入翻番"不是愿景——它没有告诉任何人该做什么，也不会让人在周一早上更有干劲。
- **不是战略、计划、预算。**科特画了一条清晰的链条：**愿景 → 战略（如何实现愿景）→ 计划（具体步骤与时间表）→ 预算（财务安排）。**四者缺一不可，但**顺序不能颠倒**。大量组织从预算开始倒推，结果是有计划无方向。
- **不是委员会写出来的口号。**科特强调，好的愿景通常经历"一个人的初步构想 → 领导联盟的反复争论与打磨 → 数月的迭代"这样一个混乱的过程。**它是被吵出来的，不是被起草出来的。**

## 领导变革第四步：沟通变革愿景

这是科特着墨最多、也最有实操价值的一步。核心命题只有一句：**你以为你说得够多了，实际上远远不够。**

他给出的沟通七要素：

**1. 简单。**去掉行话、缩写、技术术语。他的标准是：**能不能让一个刚入职的新人听懂？**

**2. 使用比喻、类比和形象的例子。**"一幅口头的图画胜过一千个词。"科特举例说，"我们要从一头大象变成一只猎豹"这样的表述，比任何精确的战略描述都更容易被记住和传播。

**3. 多渠道、反复重复。**大会、小组会、一对一、邮件、内刊、非正式对话——同一个信息用不同形式反复出现。科特的建议是：**每一次会议、每一次沟通，都应该顺带回到愿景。**

**4. 以身作则——这是最重要的一条。**

科特把这称为"**用行为沟通**"（walk the talk），并且认为它的效力压倒其他所有方式。**员工判断变革是不是真的，看的不是高层说什么，而是高层做什么。**

一次不一致的行为，可以摧毁几个月的沟通。比如：宣布要削减成本，然后管理层订购了新的行政专机；宣布要以客户为中心，然后在客户投诉和内部报表冲突时选择了报表；宣布要容忍失败鼓励创新，然后第一个失败的项目负责人被调离。

**5. 公开解释看起来不一致的地方。**如果因为客观原因出现了与愿景冲突的决策，必须主动说明，否则人们会自行填补解释，而他们填的通常是最坏的版本。

**6. 双向沟通。**科特强调，沟通不是广播。**必须留出让人提出质疑的渠道，并认真回答。**沉默不代表认同，通常代表放弃。

**7. 倾听并再倾听。**领导者需要听到愿景在传播过程中被理解成了什么样子——**它往往与你的原意相去甚远。**

## 领导变革第五步：善于授权赋能

前四步做完，人们理解了、也想行动了。这一步要处理的是：**为什么他们还是没有行动？**

科特的答案是：**因为结构性的障碍还在。**他把障碍分成四类：

### 一、组织结构的障碍

比如愿景要求以客户为中心，而组织按产品线切分，一个客户要面对七个业务部门。**结构如果与愿景冲突，员工每天都在被结构惩罚。**

### 二、技能的障碍

新的做法需要新的能力。**如果只做态度动员而不做技能训练，人们不是不愿意，而是不会。**科特特别指出，变革所需的培训往往**不只是技术技能，还包括社交与态度层面的转变**，而这类培训通常被削减掉。

### 三、系统的障碍

**这是最隐蔽也最致命的一类。**核心是**人力资源系统与信息系统**：

- 绩效考核仍在按旧指标打分；
- 晋升标准仍在奖励旧行为；
- 薪酬制度让协作者吃亏、让本位主义者受益；
- 信息系统拿不到新战略所需的数据。

**科特的判断很硬：如果考核和晋升没有改变，那么无论说什么，实际的信息是"变革不是真的"。**这与第 4 章列维特的诱因原理完全一致——**人对激励的反应，永远压倒对号召的反应。**

### 四、"挡路的管理者"

**最难的一类。**某位有实权的中层或高层，公开表态支持，实际上处处设卡。

科特对此的建议既现实又强硬：**必须坦率地与他对话，给出明确的选择，并且在必要时采取行动。**因为**组织中的每一个人都在看这件事的处理结果**——它比任何一次演讲都更能说明变革的严肃程度。

同时他也提醒：**不要把所有反对者都当成敌人。**很多抵制来自合理的担忧、来自信息不足、或来自过往变革的失败经验。**先弄清楚抵制的原因，再决定处理方式。**

## 领导变革第六步：积累短期胜利

科特对时间给了明确的数字：**大规模变革应当在 6 到 18 个月内产生可见的绩效改善。**超过这个窗口而拿不出成果，变革基本上就危险了。

### 什么才算"短期胜利"

科特给了三条标准，缺一不可：

1. **可见的**——大量人能亲眼看到结果是真实的，而不是被包装出来的；
2. **明确的**——不容争辩，不需要解释才能理解；
3. **与变革努力明确相关的**——人们能看出它是因为变革才发生的。

### 短期胜利的六个作用

1. **提供证据**，证明这些付出是值得的；
2. **奖励变革者**，让付出的人得到认可（拍拍肩、发奖金、公开表扬）；
3. **微调愿景与战略**——从实际结果中学习，修正方向；
4. **削弱怀疑者与阻挠者**——**这一条尤其重要**：可见的成果让公开反对变得困难；
5. **维持上级与关键干系人的支持**；
6. **建立势能**——把中间派拉过来。

### 关键的区分："胜利"是被创造的，不是被祈祷的

科特强调，短期胜利**必须被主动规划和设计**，而不是"希望它自然发生"。

这意味着：在变革启动之初，就要有意识地挑选一两个**周期短、把握大、可见度高**的项目优先推进，即使它们不是最重要的。**它们的价值不在于自身的收益，而在于为整个变革提供燃料。**

同时要警惕一个陷阱：**为了短期胜利而牺牲长期目标。**如果所有资源都投入到容易出成绩的地方，变革就会退化成一堆表面工程。

---

## 领导变革第七步：促进变革深入

这一步针对的是"过早宣布胜利"这个错误。

科特的核心主张是：**短期胜利应当被用作推动更大变革的燃料，而不是终点线。**

他描述的正确姿态是：**每一次成功之后，紧迫感不是下降而是被重新点燃。**领导者应当利用刚获得的公信力，去动那些原本不敢动的系统——组织结构、核心流程、人事任命、乃至最难改的考核体系。

他给出的几条具体做法：

- **发起更多、更大的变革项目**，把更多人卷进来；
- **引入和提拔能够实施新愿景的人**——人事任命是最强的信号；
- **由高层持续保持紧迫感**，不断把注意力引向"还没有完成的部分"；
- **由中层负责具体项目的领导**，而不是所有事都由高层推动。**这是变革从"少数人的事"变成"多数人的事"的关键转折。**
- **减少不必要的相互依赖**——科特特别提到，变革后期最大的阻力常常来自过度复杂的内部依赖关系，简化它们本身就是变革的一部分。

**这一步的时间跨度是以年计的。**科特反复说：真正的组织转型需要三到十年。**任何声称在六个月内完成了企业转型的说法，说的都是项目结束，而不是变革完成。**

---

## 领导变革第八步：成果融入文化

科特对文化的定义是：**群体中共享的行为规范与价值观。**它极难改变，因为它是无形的、不被讨论的、并且是通过日常互动传递的。

**这一步最重要的洞察是关于顺序的：**

> **文化不是在变革之初被改变的，而是在变革之末被改变的。**

科特明确反对那种"先改文化，再改业务"的做法。他的逻辑是：**人们只有在亲眼看到新做法确实带来了更好的结果之后，才会真正相信新的价值观。**

因此他给出的路径是：

1. **先做出成果**；
2. **大量地、明确地向人们说明"这些成果是新做法带来的"**——科特强调这一步不能省，因为**人们完全可能把改善归因于其他原因**（运气、市场、某位英雄）；
3. **确保新一代的管理者体现新做法**——**尤其是接班人的选择**。

**最后一条是全书对企业最有杀伤力的建议之一。**科特说：**如果继任者不体现新的价值观，那么之前所有的努力都可能在一两年内被逆转。**因此变革的最后一项工作，是重塑晋升与继任的标准。

他举了一个反面例子的模式：一位强力的 CEO 完成了艰难的转型，功成身退，董事会按传统标准选了一位"稳健的"继任者——**而这位继任者恰恰是旧文化培养出来的人。**三年后，一切回到原点。

---

## 结语：VUCA 时代，保持终身学习

《领导变革》出版近三十年后，科特自己修改了这个模型。这一节讲的就是这个修改，以及这本书今天的读法。

### 科特自己的修正：从"步骤"到"加速器"

2012 年起，科特在《加速》（*Accelerate*，2014）中提出了一个重要转向：

**第一，八个"步骤"改称八个"加速器"（accelerators）。**核心区别是：**步骤是顺序执行的，加速器是可以并行、持续运行的。**科特承认，原始模型给人的线性印象在快速变化的环境中是有害的——**你不可能等第一步完成了再做第二步，因为环境不会等你。**

**第二，从"领导联盟"到"志愿军"。**原模型依赖一个小规模的高层联盟；新模型主张动员组织中 **5%～10% 的员工**自愿参与变革网络——他们来自各个层级和职能，**因为想参与而参与，不是因为被指派。**

**第三，最重要的一条：双系统组织（dual operating system）。**

科特认为，成熟组织的层级结构在**执行**上极其高效，但在**发现机会和快速响应**上先天不足。他主张的不是废除层级，而是在层级之外**并行运行一个网络型的第二系统**：

| | 层级系统 | 网络系统 |
| --- | --- | --- |
| 擅长 | 可靠、高效地执行已知的事 | 发现机会、敏捷、创新 |
| 结构 | 科层、岗位、KPI | 志愿、跨界、临时联盟 |
| 驱动 | 管理 | 领导 |
| 人员 | 全员 | 自愿参与者（含在层级中任职者） |

**两个系统共享同一批人和同一个愿景，但用不同的规则运行。**这个模型是科特对"如何在保持效率的同时保持敏捷"这个经典难题给出的答案。

### 需要保持的批评意识

**第一，模型的线性倾向。**即使改称加速器，八步的框架仍然带有"自上而下、有序推进"的假设。现实中的变革往往是混乱的、多线并进的、经常回退的。

**第二，实证基础较弱。**与第 2 至第 5 章的实证研究不同，这个模型来自观察与归纳，没有对照组，也没有严格检验。**它是一份有价值的经验清单，不是一个被验证的理论。**

**第三，自上而下的视角。**模型基本假定变革由高层发起。而现实中大量有效的变革是从边缘开始、逐渐扩散的。**科特后来的"志愿军"概念部分回应了这个批评。**

**第四，与其他模型的关系。**勒温的"解冻—变革—再冻结"三阶段模型更简洁；ADKAR 模型更聚焦个体层面的转变（认知—愿望—知识—能力—巩固）。**它们不是竞争关系，而是不同的抽象层次：科特处理组织层面的社会过程，ADKAR 处理个人层面的心理过程。**

### 今天最该带走的三条

**第一，先建立紧迫感，并且要区分它与焦虑。**这是全书最重要、也最常被跳过的一步。一个组织如果只是很忙很焦虑，那不是紧迫感，那是虚假紧迫感，**它比自满更危险，因为它会骗过管理层。**

**第二，沟通量至少要放大一个数量级，而且行为的分量远大于言辞。**你以为说够了的时候，才刚刚开始。**而一次与愿景相悖的高层行为，抵得过一百场动员会。**

**第三，如果考核和晋升没有变，那么变革就没有发生。**这是本书与第 4 章诱因原理、第 6 章德鲁克的 MBO 之间最硬的一条连线。**组织真正的价值观，写在它的晋升名单上，不写在它的墙上。**

最后是科特自己在书末给出的那个更大的判断，它解释了这本书的标题为什么是"领导"变革而不是"管理"变革：

> **21 世纪的组织需要的不是更多的管理者，而是更多的、分布在各个层级的领导者。**

**而领导力的核心，是终身学习的能力**——科特在最后一章专门论述了这一点。他观察到那些在长期职业生涯中持续保持竞争力的人，有一组共同的习惯：**主动承担风险、谦逊地反思自己的成败、主动征求他人意见、认真倾听、以及对新想法保持开放。**

**这一条与第 7 章本尼斯"反思经验"的结论，以及下一章圣吉"学习型组织"的主题，是同一件事在三个层面上的展开：个人、组织、系统。**

## 本章要点回顾

| 主题 | 核心结论 |
| --- | --- |
| "70% 失败率" | 缺乏可靠原始出处；科特真正的贡献是"失败有固定模式" |
| 变革的性质 | 是领导问题不是管理问题；用管理方法做变革是失败的普遍原因 |
| 八大错误 | 自满、联盟不强、低估愿景、沟通不足、障碍未除、无短期胜利、过早庆功、未入文化 |
| 第一步 紧迫感 | 需约 75% 管理层认同现状不可接受；区分自满、虚假紧迫感、真实紧迫感 |
| 虚假紧迫感 | 忙碌与焦虑不是紧迫感，且比自满更危险，因为它会骗过管理层 |
| 第二步 领导团队 | 需职位权力、专业能力、公信力、领导力四要素 + 内部信任；排除大自我与毒蛇 |
| 第三步 愿景 | 六特征：可想象、可期望、可行、聚焦、灵活、可沟通（五分钟讲清） |
| 愿景的链条 | 愿景 → 战略 → 计划 → 预算，顺序不可颠倒 |
| 第四步 沟通 | 通常少了 10～1000 倍；七要素中以身作则最重要 |
| 第五步 赋能 | 四类障碍：结构、技能、系统（尤其是考核与晋升）、挡路的管理者 |
| 第六步 短期胜利 | 6～18 个月内需可见成果；必须被主动设计而非等待发生 |
| 第七步 深入 | 用胜利作燃料而非终点；转型以年计，中层接手项目领导是关键转折 |
| 第八步 入文化 | 文化最后才变；必须明示"成果源自新做法"；继任者标准是最后一道关 |
| 科特的自我修正 | 步骤改为可并行的加速器；小联盟改为志愿军；提出层级+网络的双系统组织 |
